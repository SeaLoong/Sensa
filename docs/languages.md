# 中英双语支持

**简体中文** | [English](languages.en.md)

## 软件里如何切换

右上角选择 **简体中文** 或 **English**。首次访问按浏览器支持的中英文偏好选择，其他语言回退英文；选择保存在本浏览器的 `sensa.locale`。存储受限时仍可在当前页面切换。

切换覆盖界面、内置预设说明、参数含义、校准与空间诊断、帮助链接、MUI 控件和时间显示。不会刷新页面、丢弃草稿、保存设备配置、改变输入模式或启用输出。用户填写的设备/轴配置/预设名称、文件内容、协议枚举与 OSC 路径保持原值。

已知 Sensa 服务端诊断在显示时翻译。未知固件、系统和第三方错误保留原文，便于排错。以前创建的自定义名称不会被追溯改名。

## Unity 与测试套件

Unity Inspector 字段与帮助同时展示中英双语，保留原英文字段术语。组件菜单名、序列化字段与生成协议不变。QuickStart 提供独立的中文、英文指南按钮。

项目用户文档、开发文档、Unity 指南和测试套件文档均提供互相链接的 `.en.md` 英文页；桌面发行包包含两种语言。Unity ZIP 包含四组 Unity 指南。

已有世界/Avatar 的可见标记保留技术英文标签及 P/C 编号，双语交互与能力文档逐项解释操作。更新文档不会自动重建或上传已有 Avatar/世界；客户端文字可见性、相机及硬件行为仍需另行验收。

## 开发时怎样维护

- Web 源码用 `t(中文原文, 参数数组)` 明确标记应用文本；英文目录为 `src/web/i18n.en.json`。
- 动态信息用 `{0}` 等占位符；用户值只替换一次，不递归翻译，也不当作 HTML。
- 不遍历替换 DOM，不翻译任意配置内容。模块选项通过函数生成，缓存计算包含语言依赖，避免切换后残留旧文本。
- 服务端动态诊断使用 `i18n-diagnostics.json` 中完整匹配的模板，捕获的名称、地址保持原值。
- 新文本同步补英文并保留相同占位符。`npm test` 校验源码键、全部预设、语言回退、存储失败和订阅行为。
- 文档成对维护，打包和链接测试检查是否遗漏英文文件或资源。
- 浏览器 E2E 与截图只在 CI 跑。英文桌面/窄屏测试覆盖持久化、草稿保留、切换不发控制请求、PB 校准与模拟输出、松手停止和帮助链接。
