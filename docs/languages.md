# 中英双语

**简体中文** | [English](languages.en.md)

顶栏选择简体中文或 English。首次访问按浏览器支持的语言选择，其他语言回退英文；偏好保存在当前浏览器，存储受限时仍可在页面内切换。

界面、基本控件、三项预设（OGB / SPS 深度、振动、PhysBone 拉伸）、参数含义、实验诊断、帮助和时间显示随语言更新。切换不会重载、丢弃草稿、保存配置、改变模式或启用输入。用户名称、文件、协议枚举和 OSC 路径保持原文；未知固件／系统／第三方错误同样保留，方便排查。

Unity Inspector 同时提供中英文标签与帮助；生成协议标识和原有技术菜单名保持可检索。公开指南成对提供语言入口，桌面包包含两种语言。文档更新不等于重新构建或上传 Avatar／世界。

## 维护

Web 文本通过 `t(中文原文, 参数)` 与英文目录维护，使用一致的 `{0}` 占位符；用户值只插入一次，不递归翻译或作为 HTML。动态服务诊断在显示边界按模板翻译，不遍历替换 DOM。

源码键、预设、占位符、语言回退、存储失败和订阅由单元契约检查；浏览器中的持久化、草稿保留和切换不发控制请求由 CI 覆盖。旧版 UI 展示截图已撤下，当前视觉以候选提交经审阅的 CI 比较为准，不复用历史截图证明新布局。
