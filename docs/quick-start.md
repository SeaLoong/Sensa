# 首次使用

**简体中文** | [English](quick-start.en.md)

目标是先验证一个小量程的命令链，再接入实际数据。需要了解检测几何时可先打开[独立参数图解](https://sealoong.github.io/Sensa/parameter-geometry.html?lang=zh-CN)，无需设备或运行 Sensa。

## 1. 启动

从 [Releases](https://github.com/SeaLoong/Sensa/releases)下载对应系统与 CPU 的包，解压运行 Sensa，打开 `http://127.0.0.1:5086`。默认配置位于程序旁 `config.json`；用 `SENSA_CONFIG_PATH` 可指定另一文件。初次测试用隔离配置，避免沿用真实设备目标。

界面按 URL、已保存选择、系统语言顺序自动识别，也可手动切换。[语言规则](languages.md)

## 2. 配置输出

在“控制”添加输出：

| 类型 | 需要确认 |
| --- | --- |
| TCode 串口 | 正确端口；115200、8N1；关闭其他占用端口的程序 |
| TCode UDP／TCP | 真实目标地址、端口和传输类型；UDP 没有执行确认 |
| Intiface | 先启动已有 Central，再填服务地址；新输出默认不管理引擎 |
| Intiface 振动 | 来源默认 V0；可选 V1／V2，只有明确选 L0 才将深度转为强度 |

保存后明确启用该输出并连接。输出显示的是最近发送命令，不是设备位置。轴配置在“设置”调整量程、限位、反向与速度；先用很小的安全范围。

## 3. 检查手动方向和停止

应用“手动”，明确启用输入，再发送一次小目标。连续发送只跟随目标修改，不自动往返。确认急停能关输入；解除后须再次启用，不会自动续动。

连接本身不打开输入，但如果输入已经启用，连接可能立即接收当前有效目标。配置变更、模式变更和脚本替换都会关闭输入。

## 4. 接入一种输入

- **OSC**：应用 OSC，核对默认监听 `127.0.0.1:9001` 和实际来源，在参数页观察真实地址。选择[三个模板](presets.md)之一，检查量程／门控后保存，再启用输入。OGB 参数可能需要接收设置中的显式启用心跳，其目标通常是 VRChat 的 9000，不能误填 Sensa 的 9001。
- **脚本**：导入有效 funscript，检查 L0 时间线、倍速及循环。应用 Script、启用输入后播放。暂停停止自动帧，但已启用 Script 时显式定位／步进仍能发送目标；Stop 重置游标，不是机械归位。
- **实验根点**：先按[方案指南](usage-scenarios.md)建立生产端，确认对象、来源与有效性，采集两端并保存映射；最后分别允许实验空间输入和启用输入。

不要把未知参数名当成准确位置。现代 OGB 是径向估算；固定 SPS 与 Shader 是 Avatar 根局部位置。[定位说明](positioning.md)

## 5. 保存可复查的结果

需要记录时使用 L0 录制。停止保留末值持续时间；导出活动录制会先停止录制，但不会关闭输入。重录需要确认，取消保留旧缓冲。录制不包含其他轴、门控／停止事件或设备回读。

出现问题先关闭输入，核对实际模式、来源、映射、门控与日志；不要通过不断重连或重发来掩盖错误。[完整操作](guide.md) · [功能参考](features.md) · [首页](../README.zh-CN.md)
