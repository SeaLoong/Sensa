# 首次使用

**简体中文** | [English](quick-start.en.md)

第一次使用时，先确认设备能在小范围内按预期移动和停止，再接入 VRChat 或动作脚本。想先了解各类参数，可直接在浏览器打开[独立参数图解](https://sealoong.github.io/Sensa/parameter-geometry.html?lang=zh-CN)。

## 1. 启动

从 [Releases](https://github.com/SeaLoong/Sensa/releases)下载对应系统与 CPU 的包，解压运行 Sensa，打开 `http://127.0.0.1:5086`。默认配置位于程序旁 `config.json`；用 `SENSA_CONFIG_PATH` 可指定另一文件。初次测试可用 `SENSA_CONFIG_PATH` 指向单独的配置文件，避免误用之前保存的设备地址。

界面按 URL、已保存选择、系统语言顺序自动识别，也可手动切换。[语言规则](languages.md)

## 2. 配置输出

在“控制”添加输出。“输出”就是 Sensa 将命令发送到的设备或服务：

| 类型 | 需要确认 |
| --- | --- |
| TCode 串口 | 正确端口；115200、8N1；关闭其他占用端口的程序 |
| TCode UDP／TCP | 真实目标地址、端口和传输类型；UDP 没有执行确认 |
| Intiface | 先启动已有 Central，再填服务地址；新输出默认不管理引擎 |
| Intiface 振动 | 来源默认 V0；可选 V1／V2，只有明确选 L0 才将深度转为强度 |

TCode 输出先在“设置”中编辑轴配置，缩小移动范围、降低速度，必要时反向；保存输出时选择这套轴配置。Intiface 的范围、速度限制和停止方式由设备／Central 提供，先确认这些设置，再用手动小目标测试。

核对目标和配置后，再启用该输出并连接。界面显示最近发送的目标值；判断设备是否到位仍需观察设备本身。

## 3. 检查手动方向和停止

选择“手动”后点击“应用输入方式”，再点击“启用输入”，发送一次小幅目标，观察方向是否正确。“连续发送”会持续发送你设置的目标值，修改目标即可改变位置。试用急停：它应立即关闭输入；解除急停后，需要再次启用输入。

输入已经启用时，新连接可能立即接收当前有效目标，因此应在连接前核对输入状态。配置变更、模式变更和脚本替换都会关闭输入，准备好后重新启用。

## 4. 接入一种输入

- **OSC**：应用 OSC，核对默认监听 `127.0.0.1:9001` 和实际来源，在参数页观察真实地址。选择[五个模板](presets.md)之一，检查输入范围及允许动作的条件（门控），保存后再启用输入。OGB 参数可能需要接收设置中的显式启用心跳：心跳发往 VRChat，通常使用 9000；Sensa 接收参数使用 9001。
- **脚本**：导入有效 funscript，检查 L0 时间线、倍速及循环。应用 Script、启用输入后播放。暂停停止自动帧；已启用 Script 时，显式定位／步进仍能发送目标。Stop 将播放游标重置到开头；需要停止设备时使用急停。
- **Contact 直接定位（SDK Beta）**：按 [Contact 设置](contact-sdk.md)安装受支持的 Beta SDK，并构建专用自身根点 Sender／Receiver。检查 `Sensa/Contact/<id>/…`；局部动作校准 X／Y／Z／Distance，运动强弱校准速度／Speed／ProximitySpeed。保存后允许实验空间输入并启用 OSC 输入。
- **实验根点**：先按[方案指南](usage-scenarios.md)设置 Avatar 测量组件或桌面图块读取程序。确认面板显示正确对象且坐标有效，再分别记录动作起点和终点，把它们对应到输出的 0% 和 100%，保存映射。最后允许实验空间输入并启用输入。

不同参数表达不同含义：OGB 通常提供接近程度或深度估算；四点定位与 Shader 提供所选根点相对 Avatar 的三维位置，Contact 直接定位提供米制位置和相对速度。[定位说明](positioning.md)

## 5. 保存可复查的结果

需要记录深度目标时使用 L0 录制，其他轴与设备状态查看对应面板和日志。停止录制会保留末值持续时间；导出活动录制会先停止录制，输入保持原状态。重录需要确认，取消时保留旧缓冲。

出现问题先关闭输入，再依次核对实际模式、来源、映射、门控与日志，定位原因后恢复。[完整操作](guide.md) · [功能参考](features.md) · [首页](../README.zh-CN.md)
