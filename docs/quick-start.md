# 首次使用

**简体中文** | [English](quick-start.en.md)

跟随设置向导选择场景、连接一个设备并准备输入。OSR／TCode 往复动作使用 L0，使用默认振动来源的 Intiface 设备使用 V0。[我的设备使用哪种连接？](devices.md)

## 1. 启动

手动控制或播放脚本时，[打开 WebSensa](https://sealoong.github.io/Sensa/websensa/)。连接串口或蓝牙设备时，建议使用桌面 Chrome 或 Edge。

使用 **VRChat／OSC** 时，[下载 Sensa](https://github.com/SeaLoong/Sensa/releases/latest)，解压 **Desktop** 包并运行。**CLI** 包会在浏览器打开同一工作台并显示地址，通常是 **http://127.0.0.1:5086**；以启动时显示的实际地址为准。

[开发预览](https://github.com/SeaLoong/Sensa/releases)也提供当前 Desktop／CLI 构建，下载入口打开最新正式版。Intel／AMD 电脑选择 **x64**，Apple Silicon／Windows ARM 选择 **ARM64**。[全部下载格式与 Linux 设置](features.md#配置与开发)

点击**开始设置向导**，选择**VRChat / SPS 联动**、**播放 funscript**或**手动控制设备**等需要的场景，再继续。WebSensa 会显示浏览器运行方式支持的场景。

之后可以通过**操作引导**打开向导。**保存进度，稍后继续**会保留当前位置，**继续设置**会返回向导。场景快捷入口可以直接打开对应控制。

## 2. 配置输出

1. 在向导中点击**连接或配置设备**，打开**控制 → 输出**。选择**输出类型**，点击**添加输出**。
2. 在**输出设置**中填写设备连接：
   - **OSR／SR6／TCode**：选择串口和端口，或填写网络地址，再选择设备的轴配置。
   - **Intiface**：启动 Intiface Central 并扫描设备，在 Sensa 填写它的 WebSocket 地址。在**设备与功能 → 匹配设备名称**中填写设备名，将控制限定到所需设备。
3. 点击**保存输出**，再点击输出卡片上的**启用**，确认连接成功。

TCode 可以在**场景预设 → 设备轴配置**中选择**设备动作预设**，点击**查看并创建轴配置**，在编辑器中检查方向与行程，再保存。随后到 TCode 输出上选择保存的轴配置。也可以在**设置 → 轴配置**中编辑。

输出可用后返回向导，继续准备输入。[其他输出类型](devices.md)

## 3. 启用输入并检查结果

在向导中点击**打开输入设置**，准备所选场景：

- **手动**：检查 L0，Intiface 振动设备则在**更多动作轴**中使用 V0。WebSensa 还需在**输出动作轴**中勾选 V0。
- **脚本**：点击**选择脚本**，载入 `.funscript`。Intiface 纯振动设备先将输出的**振动来源**设为 **L0 · 深度转振动**。
- **VRChat／SPS**：接收 OSC 参数，选择映射预设，校准并保存映射。[OGB／SPS 步骤](usage-scenarios.md#已有-ogb--sps)
- **网站或软件**：配置协议输入，让上游应用连接。[协议输入步骤](protocol-inputs.md)

如果显示**应用输入方式**，点击它。返回向导，检查输出与准备好的输入，再点击**完成设置**。完成向导会记录进度，并返回**控制**中所选的输入。准备好后再单独打开**输入启用**。

首次手动动作时，小幅调整滑条，再点击**发送一次**。**连续发送**会跟随之后的调整。播放脚本时，启用输入后点击**播放**。

输出卡片显示连接状态与最近数值。如果没有动作，检查设备／端口、输出**启用**、当前应用的输入方式和**输入启用**。

结束时关闭**输入启用**。**紧急停止**会停止所有输出，并保持到手动解除。保存设置、切换输入方式或更换脚本后，输入会关闭，准备好再重新启用；解除急停后也需要单独启用输入。

## 4. 选择来源并添加计算

通过场景快捷入口切换任务，或重新打开**操作引导**跟随步骤。**场景预设**可以查看 OSC 与设备动作预设。载入预设会准备可编辑的草稿，保存后才会改变运行配置。

首次连接成功后，可以使用[计算信号](computed-signals.md)混合输入或平滑响应。[按目标选择方案](usage-scenarios.md)介绍更多输入与 Avatar 定位选择。

## 5. 保存录制与整套方案

[录制与回放](signal-pipeline.md#录制与观察)可以将交互保存为 funscript。[整套方案](signal-pipeline.md#保存与复用整套方案)一起保存映射、计算、轴配置和输出。

浏览器设置与向导进度保存在本地；关闭或刷新网页前，请下载已完成的浏览器录制。[WebSensa 连接说明](websensa.md) · [工作台地图](guide.md) · [全部指南](start.md)

## 运行多个实例

再次打开同一桌面配置会复用已经运行的服务。需要独立设置时，使用命名实例：

```sh
Sensa --instance studio
Sensa --new-instance
```

命名配置保存在原配置旁的 `instances/<name>/config.json`。当前监听地址可在控制台／工作台查看。`--config <path>` 指定配置文件，`--open-browser false` 让 CLI 在后台运行。[配置位置与运行说明](architecture.md)
