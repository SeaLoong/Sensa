# 首次使用

**简体中文** | [English](quick-start.en.md)

跟随设置向导选择场景、连接一个设备并准备输入。OSR／TCode 往复动作使用 L0，使用默认振动来源的 Intiface 设备使用 V0。[我的设备使用哪种连接？](devices.md)

## 1. 启动

手动控制或播放脚本时，[打开 WebSensa](https://sealoong.github.io/Sensa/websensa/)。连接串口或蓝牙设备时，建议使用桌面 Chrome 或 Edge。

使用 **VRChat／OSC** 时，[下载 Sensa](https://github.com/SeaLoong/Sensa/releases/latest)，解压 **Desktop** 包并运行。**CLI** 包会在浏览器打开同一工作台并显示地址，通常是 **http://127.0.0.1:5086**；以启动时显示的实际地址为准。

[开发预览](https://github.com/SeaLoong/Sensa/releases)也提供当前 Desktop／CLI 构建，下载入口打开最新正式版。Intel／AMD 电脑选择 **x64**，Apple Silicon／Windows ARM 选择 **ARM64**。[全部下载格式与 Linux 设置](features.md#配置与开发)

从**输入**页标题旁的**操作引导**开始。桌面版默认选择 OSC，以 L0 主轴为例；也可以改选其他输入。WebSensa 默认使用手动输入。

在引导的**轴映射 → 先试横移示例**中，把左右位置从 0 调到 0.04 m：L2 会从 500 缓慢到达 560，L0 保持 500。**连接设备 → 打开 3D 模拟器**可以单独试六个轴。关闭模拟器后会回到刚才的引导步骤，草稿和设备状态保持原样。

**保存并退出**保留进度，**继续设置**返回上次步骤。直接使用工作台时，在输入页切换对应的输入标签。

## 2. 跟随高亮区域准备输入

向导按照**选择场景 → 准备输入 → 轴映射 → 轴配置 → 连接设备 → 查看日志 → 检查并完成**前进。每步提供具体操作顺序，同时高亮当前左侧导航（窄屏为顶部导航）与真实控件。可以直接操作高亮控件，用 **Tab／Shift+Tab** 在引导、导航和控件之间移动；在高亮导航上使用方向键切页时，引导同步到对应步骤。映射、变换与设备动作模板就在各自页面内。需要跳步时展开**跳转步骤**。说明较长时只滚动说明区，**上一步／下一步**和急停始终保留。打开编辑器会暂停引导，关闭后继续；按 **Escape** 保存进度退出。**诊断**页每次进入默认展开日志，也可手动收起。

在**输入**准备所选场景；打开页签本身不会应用输入方式：

- **手动**：检查 L0。Intiface 振动设备使用默认来源时，在**更多动作轴**中使用 V0；WebSensa 还需在**输出动作轴**中勾选 V0。
- **脚本**：点击**选择脚本**，载入 `.funscript`。Intiface 纯振动设备可将输出的**振动来源**设为 **L0 · 深度转振动**。
- **VRChat／SPS**：保持顶栏的**输入启用**关闭。在**输入 → OSC**确认已勾选**启用 OSC**，核对接收地址和端口；改过设置就点**保存 OSC 设置**。点**应用输入方式**选用 OSC，看到**监听中**后，在向导点**查看收到的参数**。[OGB／SPS 步骤](usage-scenarios.md#已有-ogb--sps)
- **网站或软件**：在**输入 → 协议**配置来源，让上游应用连接。[协议输入步骤](protocol-inputs.md)

## 3. 选择映射、变换与轴配置

1. 保持**输入启用**关闭。在**输入 → OSC → 参数**找到一个数值随你的动作变化的参数，记下它的路径。
2. 首次设置时，在向导里点**追加 L0 示例**；已有映射则点**编辑轴映射**，不必再追加。在**映射与变换 → 轴映射**把参数路径（示例为 `Depth`）换成刚才收到的路径，目标轴选 L0。再做一次同样的动作：**实时输入**应显示收到的数值，**预估位置**应在设定的行程内随之变化。这是预览，不是设备反馈。
3. 如果显示**未命中**，先回参数列表确认该来源仍在发送、路径与映射行一致；列表里也没有数据时，检查 VRChat 是否已启用 OSC，以及发送端的目标地址和端口是否与 Sensa 的监听设置匹配。预览符合预期后点击**保存更改**；保存后输入仍然关闭。

普通映射到这里就完成了。只有读数抖动或需要混合多个参数时，才用**计算信号**做平滑或加权平均。手动、脚本和协议输入已经提供所需轴时，可跳过映射。TCode 设备接下来在**轴配置**检查行程、方向和速度，保存后在输出中选用。[预设参考](presets.md)

## 4. 连接输出、检查并启用

1. 在向导的连接设备步骤点击**连接或配置设备**，或直接打开**输出**。选择**输出类型 → 添加输出**。
2. 在**输出设置**填写连接。**OSR／SR6／TCode**：选择串口或网络地址和保存的轴配置；**Intiface**：填写 Central 的 WebSocket 地址，在**设备与功能 → 匹配设备名称**限定目标设备。
3. 点击**保存输出**，再**启用**输出卡片，确认连接成功。[其他输出类型](devices.md)
4. 回到**输入**，需要时点击**应用输入方式**。向导最后一步显示实际准备状态；未准备好时，点击对应的**准备输入**或**连接设备**返回补设。缺少输入、OSC 轴映射或可用输出时，可点击对应项目补设，或用**稍后继续**保留进度。准备就绪后，**完成引导**只记录进度，不启用输入。
5. 准备好后单独打开顶栏的**输入启用**。首次手动动作小幅调整滑条并**发送一次**；脚本则点击**播放**。到**输出**查看设备状态与最近数值。

结束时关闭**输入启用**。**紧急停止**会停止所有输出，并保持到手动解除。保存配置、切换输入方式或更换脚本后，输入会关闭；解除急停后也需单独启用输入。计算、映射和输出连接可以分别编辑，跨页切换保留未保存草稿。

## 5. 保存录制与整套方案

[录制与回放](signal-pipeline.md#录制与观察)可以将交互保存为 funscript。[整套方案](signal-pipeline.md#保存与复用整套方案)一起导出已保存的映射、计算、轴配置和输出，需要包含最新编辑时先保存更改。

浏览器设置与向导进度保存在本地；关闭或刷新网页前，请下载已完成的浏览器录制。[WebSensa 连接说明](websensa.md) · [工作台地图](guide.md) · [全部指南](start.md)

## 运行多个实例

再次打开同一桌面配置会复用已经运行的服务。需要独立设置时，使用命名实例：

```sh
Sensa --instance studio
Sensa --new-instance
```

命名配置保存在原配置旁的 `instances/<name>/config.json`。当前监听地址可在控制台／工作台查看。`--config <path>` 指定配置文件，`--open-browser false` 让 CLI 在后台运行。[配置位置与运行说明](architecture.md)
