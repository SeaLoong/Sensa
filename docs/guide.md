# 工作台指南

**简体中文** | [English](guide.en.md)

本页帮助你找到控制。[使用指南](start.md)按任务选择入口，[首次使用](quick-start.md)跟随设置向导完成从目标到首次连接的步骤。

| 打开 | 用来做什么 |
| --- | --- |
| **输入** | 选择手动、脚本、OSC 或协议来源，查看收到的参数 |
| **映射与变换** | 输入到轴的映射、可复用计算、整套方案的导入导出 |
| **轴配置** | 从设备预设开始，校准行程、方向与速度 |
| **输出** | 连接设备、应用与录制，编辑输出连接 |
| **诊断** | 查看运行日志 |

## 操作引导与配置模板

**开始设置向导**依次经过七步：**选择场景 → 准备输入 → 轴映射 → 轴配置 → 连接设备 → 查看日志 → 检查并完成**。每一步自动打开对应页面，给出具体操作顺序，同时高亮当前导航项与真实控件。可以直接操作高亮控件；在高亮导航项上用方向键切换页面时，引导也会同步到对应步骤。打开编辑器时引导暂停，关闭后恢复。按 **Escape** 或点击**保存并退出**保留当前位置，引导中始终保留急停。缺少输入、OSC 轴映射或可用输出时，可点击对应项目补设，或用**稍后继续**保留进度。准备就绪后，**完成引导**只记录进度，不启用输入或修改配置。

配置模板分别位于**映射与变换 → 轴映射**的预设选择器、**计算信号 → 常用变换**和**轴配置 → 设备动作预设**，不再使用独立的总预设弹窗。映射和计算先载入可编辑草稿，再明确保存；轴模板在编辑器检查行程、方向与速度后保存，随后由 TCode 输出选择使用。载入模板不会启用输入。

控制页的输入页签可直接切换手动、脚本或 OSC 设置。

## 准备、应用输入方式，再启用输入

准备来源与输出并保存，再点击**应用输入方式**，打开**输入启用**。打开页签用于准备其中的控制。保存配置、切换方式或载入脚本后，输入会关闭；解除**紧急停止**后也需要单独启用输入。

**映射与变换**中的**保存更改**一起保存所有计算信号与轴映射草稿，包括在另一个分段页签做的编辑。**恢复更改**将两者一起恢复到已保存状态。输出连接则单独使用**保存输出**。无法保存时，工具栏会指出未填完整的草稿，并提供前往对应工作区的入口。

## 输入

### 手动与脚本

位置往复动作使用 L0，使用默认振动来源的 Intiface 设备则在**更多动作轴**中调整 V0。**发送一次**发送选定目标，**连续发送**跟随调整。播放 funscript 时，选择**脚本**、载入文件、应用输入方式，启用输入后点击**播放**。[播放器、振动来源与浏览器步骤](websensa.md#手动控制与脚本)

### 组合输入

多个不同种类的来源需要一起参与时，选择组合输入。[完整示例](signal-pipeline.md#同一个结果连接多个输出)

### 输出

在**输出**选择**输出类型 → 添加输出**，填写设置并**保存输出**，再**启用**卡片。这里显示连接状态、设备操作与最近数值。[输出设置与绑定](signal-pipeline.md#添加输出与绑定)

### 接收网站的串口或蓝牙指令

兼容播放器使用[协议输入](protocol-inputs.md)，串口／蓝牙来源使用[桥工具](../tools/protocol-bridge/README.zh-CN.md)。

### L0 录制

**输出 → 录制 L0 目标**记录主轴轨迹，**停止录制并导出**将它保存为 funscript。

### 录制输出

在**输出**添加**信号录制**输出，可以选择来源、保存多条轨道或诊断数据。[录制与回放](signal-pipeline.md#录制与观察)

## OSC

在**输入 → OSC**中，通过**参数**和**实验诊断**分段页签选择视图；映射单独位于**映射与变换**。这些页签用于准备设置，不应用输入方式。

### 参数与来源

先在**输入 → OSC**确认**启用 OSC**已勾选，核对接收地址与端口；更改后点**保存 OSC 设置**。点**应用输入方式**选用 OSC。看到**监听中**后，在向导点**查看收到的参数**，或直接打开**参数**页签。保持顶栏**输入启用**关闭即可查看数值。**浏览来源**筛选显示，**使用来源**选择映射使用的来源。[参数字典](osc-parameters.md)

### 没有得到预期结果时先看哪里？

映射行显示**未命中**时，回到参数列表，确认选用的来源正在发送该路径；若路径不同，按列表中的实际路径修改映射。列表中也收不到值时，再核对发送端的目标地址、端口和 Sensa 的监听设置。排查时不需要启用输入。

### 将输入变为动作（映射）

在**输入 → OSC → 参数**找一个随动作变化的数值参数，点击该行的**映射**。在**映射与变换 → 轴映射**确认目标轴为 L0；重复动作，比较同一行的**实时输入**和**预估位置**。如果行程或方向不对，先调整范围或反向，再点击**保存更改**。保存后输入保持关闭。[OGB／SPS 步骤](usage-scenarios.md#已有-ogb--sps) · [模板参考](presets.md)

### 先融合输入（计算信号）

一个轴需要综合多个读数时，可给当前映射加一个加权平均步骤。每个输入的权重决定它对结果的影响。[计算示例](computed-signals.md)

### 接收、发现与转发

OSC 设置包括监听地址、OSCQuery 发现、Hub 转发与 **OGB 参数启用**。VRChat 常用发送目标端口为 **9001**，接收端口为 **9000**。[端口与路由](protocol-inputs.md)

### 从根点位置控制：先查看，再校准

选择[定位方案](usage-scenarios.md)，检查有效读数并采集动作端点，再启用空间输入。[单位与校准](positioning.md)

## 映射与变换

**轴映射**决定把哪个来源送到哪根轴。一个参数直接驱动 L0 时，计算步骤可以保持折叠。

读数抖动需要平滑，或多个读数需要混合时，再展开该行的计算步骤。追加一步或点击已有步骤会打开**计算信号**；调整后点**返回当前映射**回到原行，不会新增映射。计算是共享的：保存后，其他引用它的映射和输出也会使用新结果。

在**输出**页展开**输出连接**可查看已保存的路由。**编辑输出连接**打开原有输出设置窗口中的绑定表单；**管理输出**定位同页的完整设备卡片。选择计算来源时使用已保存的结果。**保存输出**单独应用这些连接，并保留尚未完成的计算／映射草稿。

**保存与载入整套方案**导出已保存配置。需要包含最新编辑时，先保存计算、映射与输出设置。[信号流程指南](signal-pipeline.md)

## 轴配置、诊断与帮助

**轴配置**设置 TCode 方向、行程与运动参数。设备动作预设可以准备新配置，保存后在输出上选择使用。协议监听在**输入 → 协议**，日志在**诊断**，每次进入默认展开。帮助可以打开[使用指南](start.md)，或重新打开操作引导。[连接参考](protocol-inputs.md) · [独立桌面实例](quick-start.md#运行多个实例)
