本页帮助你找到控制。[使用指南](start.md)按任务选择入口，[首次使用](quick-start.md)跟随设置向导完成从目标到首次连接的步骤。

| 打开 | 用来做什么 |
| --- | --- |
| **输入** | 选择手动、脚本、OSC 或协议来源，查看收到的参数 |

## 操作引导与场景预设

**开始设置向导**依次经过六步：**选择场景 → 准备输入 → 映射与变换 → 轴配置 → 连接设备 → 检查并完成**。每一步自动打开对应页面，高亮真实控件并变暗其余区域，可以直接操作高亮控件。打开编辑器时引导暂停，关闭后恢复。按 **Escape** 或点击**保存进度，稍后继续**保留当前位置，引导中始终保留急停。**完成引导**只记录进度，不启用输入或修改配置。

**场景预设**分为 **VRChat / OSC 映射**、**常用变换**、**设备轴配置**三组。卡片先说明用途，再载入可编辑草稿。映射含 SPS 深度与振动组合；变换含手动平滑、手动与脚本混合、阈值开关和缓慢往复。载入后检查并明确保存；TCode 输出单独选择已保存的轴配置。

场景快捷入口打开对应任务的控制。选择场景或预设不会启用输入。

## 准备、应用输入方式，再启用输入

准备来源与输出并保存，再点击**应用输入方式**，打开**输入启用**。打开页签用于准备其中的控制。保存配置、切换方式或载入脚本后，输入会关闭；解除**紧急停止**后也需要单独启用输入。

**映射与变换**中的**保存更改**一起保存所有计算信号与轴映射草稿，包括在另一个分段页签做的编辑。**恢复更改**将两者一起恢复到已保存状态。输出连接则单独使用**保存输出**。无法保存时，工具栏会指出未填完整的草稿，并提供前往对应工作区的入口。

## 控制

### 手动与脚本

位置往复动作使用 L0，使用默认振动来源的 Intiface 设备则在**更多动作轴**中调整 V0。**发送一次**发送选定目标，**连续发送**跟随调整。播放 funscript 时，选择**脚本**、载入文件、应用输入方式，启用输入后点击**播放**。[播放器、振动来源与浏览器步骤](websensa.md#手动控制与脚本)

### 组合输入

多个不同种类的来源需要一起参与时，选择组合输入。[完整示例](signal-pipeline.md#同一个结果连接多个输出)

### 输出

在**输出**选择**输出类型 → 添加输出**，填写设置并**保存输出**，再**启用**卡片。这里显示连接状态、设备操作与最近数值。[输出设置与绑定](signal-pipeline.md#添加输出与绑定)

### 接收网站的串口或蓝牙指令

兼容播放器使用[协议输入](protocol-inputs.md)，串口／蓝牙来源使用[桥工具](../tools/protocol-bridge/README.zh-CN.md)。

### L0 录制

**输出 → 录制 L0 目标**记录主轴轨迹，**停止录制并导出**将它保存为 funscript。

### 录制输出

在**输出**添加**信号录制**输出，可以选择来源、保存多条轨道或诊断数据。[录制与回放](signal-pipeline.md#录制与观察)

## OSC

在**输入 → OSC**中，通过**参数**和**实验诊断**分段页签选择视图；映射单独位于**映射与变换**。这些页签用于准备设置，不应用输入方式。

### 参数与来源

找到收到的参数并检查数值。**浏览来源**筛选显示，**使用来源**选择映射使用的来源。[参数字典](osc-parameters.md)

### 没有得到预期结果时先看哪里？

先检查接收状态与发送端口，再检查来源选择、已保存映射、输出连接与**输入启用**。输入关闭时，预览仍可更新。

### 将输入变为动作（映射）

打开**场景预设**，选择 OSC 预设并载入**映射与变换 → 轴映射**；也可以使用其中的预设选择器。选择参数或计算结果，校准量程／方向后**保存更改**。[OGB／SPS 步骤](usage-scenarios.md#已有-ogb--sps) · [模板参考](presets.md)

### 先融合输入（计算信号）

需要混合、平滑或条件时，在**映射与变换 → 计算信号**选择变换预设或创建计算，再在**轴映射**中选择它的结果。[计算示例](computed-signals.md)

### 接收、发现与转发

OSC 设置包括监听地址、OSCQuery 发现、Hub 转发与 **OGB 参数启用**。VRChat 常用发送目标端口为 **9001**，接收端口为 **9000**。[端口与路由](protocol-inputs.md)

### 从根点位置控制：先查看，再校准

选择[定位方案](usage-scenarios.md)，检查有效读数并采集动作端点，再启用空间输入。[单位与校准](positioning.md)

## 映射与变换

**计算信号**统一在**映射与变换**中创建与编辑。计算卡片中的**用于轴映射**会打开同页的**轴映射**并添加草稿，检查后再**保存更改**。

在**输出**页展开**输出连接**可查看已保存的路由。**编辑输出连接**打开原有输出设置窗口中的绑定表单；**管理输出**定位同页的完整设备卡片。选择计算来源时使用已保存的结果。**保存输出**单独应用这些连接，并保留尚未完成的计算／映射草稿。

**保存与载入整套方案**导出已保存配置。需要包含最新编辑时，先保存计算、映射与输出设置。[信号流程指南](signal-pipeline.md)

## 设置与帮助

**轴配置**设置 TCode 方向、行程与运动参数。设备动作预设可以准备新配置，保存后在输出上选择使用。协议监听与日志也在这里。帮助可以打开[使用指南](start.md)，或重新打开操作引导与场景预设。[连接参考](protocol-inputs.md) · [独立桌面实例](quick-start.md#运行多个实例)
