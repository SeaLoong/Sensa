# 工作台使用指南

**简体中文** | [English](guide.en.md)

工作台分为三个主区：“控制”负责手动、脚本和设备；“OSC”负责接收参数并把它们转换为动作；“设置”负责轴范围、速度和日志。顶栏显示当前连接、正在使用的输入方式、输入是否启用以及急停状态，弹窗内也能急停。第一次连接请先看[首次使用](quick-start.md)。

## 为什么选了页签还没有动作？

浏览手动／OSC／脚本页签只选择正在编辑的内容。点击“应用输入方式”才改变实际模式；再点击“启用输入”，才允许该方式控制设备。准备状态会列出还缺哪些步骤，但不会自动启用。无输出时可直接添加，帮助中的方案入口只导航，不发送控制。

保存配置、更换实际模式、导入／替换脚本先关闭输入并停止。急停锁存；解除急停不恢复动作。输出连接与启用独立；已有有效输入许可时，新连接可能接收当前目标。断线重连不会重放未完成的浏览器请求。

## 控制

### 手动与脚本

手动先显示 L0／L1／L2，旋转、振动和辅助轴在展开区内，共十二轴。编辑数值／滑条后发送一次，或允许持续跟随修改。“发送设置”选择跟随轴配置、指定时长 I（ms）或指定速度 S；默认数值是速度上限，不是时长。清除覆盖不等于设备回中。

funscript 导入后显示时间、轨迹密度与播放控制。支持 0.1–4 倍速、循环、A–B、时码与关键帧定位；暂停保持游标，Stop 归零游标，卸载清除文件。暂停时显式定位／步进仍可在 Script 输入已启用时发送。没有媒体同步或机械归位功能。

### 输出

每条输出按名称／目标／操作排列，可编辑、启用、连接与断开；详细诊断按需展开。

- TCode 串口使用 115200／8N1，可枚举端口并请求设备信息；UDP／TCP 使用明确地址与端口。
- Intiface 默认连接外部 Central。仅明确自管时设置引擎端口；包不附带引擎。可扫描、停止扫描并查看设备特征。
- 振动来源默认 V0，可选择 V1、V2 或显式 L0。位置特征使用自己的命令能力，纯振动设备不需要位置特征；V0=0 不会因 L0 非零而振动。
- 轴配置决定 TCode 的移动范围、方向、限位与运动方式。输出详情中的位置和时间戳记录已发送的命令；它们不是设备返回的实际位置。

### L0 录制

录制分发前的 L0 命令，不依赖硬件回读。停止会保留末值保持时间；达到 100000 帧自动结束。活动导出先停止录制；停止录制不关闭输入。重新开始需确认清空旧缓冲，取消保留它。

导出为 funscript actions，可简化轨迹。它不包含多轴、输入许可、门控／停止事件、视频时钟或设备确认，不能直接作为完整安全事件记录。

## OSC

### 参数与来源

先应用 OSC 并检查监听，再观察参数。来源浏览与“使用来源”分开；只有后者改变实际信号来源。先用搜索和分类缩小列表，再置顶常看参数。“冻结预览”只暂停参数列表的显示更新，接收、映射和设备控制仍继续运行；要停止动作，请关闭输入或使用急停。“显示 FT 参数”只控制 FT／v2 根前缀，已映射和置顶参数保留，不按表情形状名称猜测。

参数表每页最多显示 100 项，使用“上一页／下一页”继续浏览。搜索、来源和分类先作用于当前目录中的全部参数，再分页显示；切换筛选条件会返回第一页，数值更新则保留当前页。这样无需一次展开几千行，也可以找到当前页以外的参数。

详情解释叶子参数、当前值和映射用途；“交互参数图解”打开本地离线页面。参数存在不代表已经映射，更不代表输入已获许可。Avatar／来源生命周期变化会清理旧值与估长状态，并停止 OSC 输入。

### 把参数转换为动作（映射）

顶部工具栏集中预设、替换／追加、保存与恢复。内置只有[深度、振动和原生 PB](presets.md)三项；自定义预设仍可保存和管理。

每行选择路径、角色、反向；高级项设置输入量程、曲线和输出区间。编辑“参数路径”时，可输入路径片段筛选建议，一次最多显示 50 项；仍可手工输入完整路径或通配符。建议只在正在编辑的字段中展开。完整段 `*`、跨段 `**` 与分号／换行别名可用。单条本地模拟用于检查变换，不证明真实来源。草稿的“未保存”在成功保存后应消失；配置保存同时关闭输入。

“门控”是允许动作的附加条件，例如目标必须足够接近。`GateEnable` 增加这类条件，`DepthOverride` 可以覆盖普通深度。多个输入同时参与时的规则见[功能参考](features.md)。模板带有不需要的条件时应移除；内部测试用的 Active 条件不应限制实际数据。

### 接收、发现与转发

展开接收与转发设置，配置监听、来源、输入超时、OSCQuery 和 Hub。

- 常规 OSC 超时默认 0（关闭），适配只在变化时发送的来源；正值对相关数据断流锁存急停。
- OSCQuery 支持参数树／HOST_INFO、LISTEN 订阅与可选轮询，也可广播本机接收服务。
- Hub 向多个 UDP 目标按事件或固定频率转发，保留未消费原始 bundle 结构；计数不是执行回执。
- OGB 参数心跳默认关闭，须明确填写 VRChat 接收目标（通常 9000）。实际 OSC 接收运行时每 5 秒发 true，停用时尝试 false；它不启用设备输入。

### 用根点位置控制动作：先观察，再校准

空间许可默认关闭。SPS／Shader 根点面板显示对象、来源、局部坐标、有效性与原因；Point／Handle／Pose 是独立实验，各自模型不可混用。

先固定要观察的对象，再选择左右 X、上下 Y、前后 Z，或距 Avatar 原点的距离。将目标移到期望的动作起点，采集为 0%；移到终点，采集为 100%。检查预览方向和范围，确认后替换映射草稿并保存。最后分别允许实验空间输入和启用当前输入。失效会停止，不回退同轴旧标量。坐标属于局部参考，不是设备、世界或最终网格位置。[定位条件](positioning.md)

## 设置与帮助

轴配置支持新增、默认、复制／编辑和移除；唯一默认配置不可直接删除，引用会按规则修复。每轴可设范围、重映射、最大速度、反向、锁定／忽略与 None／Interval／Speed／Ramp。日志可按级别筛选，保留原始诊断便于排查。

帮助连接到[三条方案](usage-scenarios.md)、[参数字典](osc-parameters.md)与安装文档。UI 和图解语言遵循[自动识别与明确选择](languages.md)，切换保留草稿。

## 参数图解的操作边界

[在线版](https://sealoong.github.io/Sensa/parameter-geometry.html?lang=zh-CN)可独立使用，发行包也可打开 `docs/parameter-geometry.html`。十场景均有 3D、XZ 与立体 SVG；3D 拖目标只改所选平面两轴，拖背景旋转，复位视角不复位参数。滑条始终可用，WebGL 失败回退 SVG。

灰色实体仅是参考截面，橙色可操作标记不是实际 Sender 半径。图解的有效性状态只回答“当前模拟条件下能否得到可用测量”，不会启用真实输入、修改 Sensa 配置或发送设备命令。“模拟收到有效样本”用于对比收到有效或无效样本时的状态；取消勾选后模拟值失效。图解、截图和 mock 测试都不替代真实客户端与硬件验收。[证据范围](ui-visual-review.md) · [首页](../README.zh-CN.md)
