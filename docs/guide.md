# 使用指南

**简体中文** | [English](guide.en.md)

浏览器打开 `http://127.0.0.1:5086`。页面只有**控制、OSC、设置**三个入口；顶栏始终显示实际模式、输入启用、急停、语言和帮助。首次设备测试见[快速开始](quick-start.md)，不同条件的方案、效果与限制见[使用方案](usage-scenarios.md)。

[交互参数图示](parameter-geometry.html?lang=zh-CN)可在发行包内离线打开，用于理解参数与几何的关系，不会连接设备。SPS／Shader 的 3D 视图可旋转、缩放；用 XYZ 滑条移动目标。缺少 WebGL2 时自动回到 SVG，数值及二维操作仍可用。

## 控制

1. 先关闭输入。在输出列表添加串口、UDP、TCP 或 Intiface，填写连接目标并选择轴配置。
2. 选择手动、OSC 或脚本；浏览页签不会改变实际模式，只有选择与实际模式不同时才显示“应用输入方式”，点击后才切换。准备状态解释当前阻断原因；快捷入口只浏览或定位配置，不会自动连接或启用。
3. 检查预览、量程和方向，再启用输入。切换实际模式、替换脚本或保存配置后需要重新启用。

| 输入 | 操作 |
| --- | --- |
| 手动 | 调整主轴后点击“发送一次”；连续发送跟随调整，不自动往返；停用取消跟随、清除覆盖，实际为手动模式时还会关闭输入并停止。斜率和速度在“发送设置”，其余轴在单独展开区 |
| OSC | 在 OSC 页保存映射，再选择来源；返回控制页启用输入 |
| 脚本 | 先选择 funscript；载入后显示时间轴、倍速、循环或 A–B，以及播放、暂停、停止、定位和关键帧步进 |

暂停会停止自动输出；已启用 Script 输入时，显式定位或步进仍可发送目标。停止归零的是播放游标，不代表设备归位。卸载或换文件不会自动续动。

输出可独立启用、连接、配置和移除。TCode 输出绑定轴配置；串口设备信息、Intiface 扫描在展开区。Intiface 默认连接现有 Central：先启动服务、扫描设备并填写 WebSocket 地址。由 Sensa 启动引擎须另行安装，程序不附带引擎。振动来源默认 V0，可选 V1／V2，只有明确选择 L0 才将深度转为振动强度；设备不必同时具备位置和振动能力。串口固定 115200、8N1；固件协议和设备权限须匹配。

输入区展开“录制 L0 目标”。它记录分发前的 L0 命令并导出 funscript，停止时保留末值到实际停止时间，达到 100000 帧自动结束。录制中导出会停止录制；重新录制须确认清空旧缓冲，可取消并先导出。停止录制不会关闭输入或停止设备。它不是设备实测轨迹或传输成功证明，输出预览同样只表示发送目标。

关闭输入会停止；急停保持锁定，解除后仍需重新启用输入。停止不保证回中或切断硬件电源。

## OSC

| 子页 | 用途 |
| --- | --- |
| 映射 | 三项内置预设、自定义预设、路径／轴／反向；展开单条以编辑量程、曲线、输入解释和模拟 |
| 参数 | 搜索、按来源浏览、分类、冻结、置顶、查看含义并添加映射 |
| 实验诊断 | 查看 Point／Handle／Root／Pose 的局部估计与失败原因；实验许可和两端校准 |

预设的替换／追加先生成草稿；预设下方的保存栏显示状态，点击保存后才应用，空白路径需先填写或移除。恢复会放弃未保存草稿。保存输出／轴配置不再覆盖映射或接收草稿，保存映射也不覆盖未保存的接收设置；刷新页面仍从已保存配置初始化。映射支持完整路径段通配 `*`、跨段 `**`，及用分号／换行列出的别名。优先固定具体实例；多个来源时，**使用来源**决定驱动，浏览来源只改变列表。

FT 默认按 `FT/`、`v2/` 命名空间前缀隐藏，完整 `/avatar/parameters/` 前缀会先移除。已映射或置顶条目保留；显示 FT 开关可查看全部。不会再靠 JawOpen 等形状名猜测。冻结只冻结浏览列表，不暂停接收或设备输出。

每个子页下方展开“接收与转发设置”：

- **监听**：默认 UDP `127.0.0.1:9001`。监听要求实际模式为 OSC 且接收已启用；与 HTTP 5086 无关。
- **OSCQuery**：远端目录、实时订阅、可选轮询回退；可广播本机接收服务便于发现。
- **Hub**：把选定来源转发到多个 UDP 目标，可按事件或固定频率合并。检查来源与目标，避免回路。
- **输入超时**：常规标量默认关闭，因 VRChat 可能只发送变化值；启用后断流会急停。门控刷新不等于运动数据刷新。

路径、标量与半径含义见[预设](presets.md)和[参数字典](osc-parameters.md)。原生 PB Stretch 可直接使用，不需要四点解算。空间输入默认关闭，完整采样和低残差也不证明可靠定位；不同生产端的时效与坐标限制见[定位说明](positioning.md)。

### 三条 SPS 使用链路

1. **已有 OGB／SPS 参数**：选择“OGB / SPS · 深度”或“OGB / SPS · 振动”，在参数列表确认具体对象，再固定路径和校准。深度自动识别现代 Root／Tip 配对或旧单近接，Touch／Frot 自动核对所需的同对象 Close；独立 VFH Touch Zone 直接读取。现代 VRCFury 可能需要 `OGB_ENABLED`；展开“OGB 参数启用”，明确填写 VRChat 控制 IP／端口并保存。默认接收端口 9001 与 VRChat 控制端口通常 9000 不同；每 5 秒心跳和停止时 false 只是发送状态，没有接收确认，也不启用设备输入。[兼容说明](ogb-compatibility.md)
2. **固定四锚点根部**：在 Unity Automatic SPS Setup 选目标；Exclusive 初始 Off，Dedicated 可同时测量。每个自身根只发布 `Sensa/SPS/<id>/{P0,P1,P2,P3,Sample}`：Sample=0 停用，活动时 1/32…1 循环。锚点固定在 Avatar 根下，半径 0.001 的 Sender 跟随实际 Socket／Plug 根，接收半径 2.5 并由内部缩放守卫限定覆盖。打开“实验诊断 → 本地点与根部”，固定对象与来源、采集两端、替换草稿并保存；不解码任何旧 Sensa SPS 布局。
3. **原生 Shader 根点**：添加 Shader Root Capture，选择 SPS 目标和 producerId；上传后显式打开生成的捕获菜单。按 [GPU／Shader 指南](../unity/top.sealoong.sensa/GPU-TRACKING.md) 注册实际像素区域与相同 producerId，用 Python 桥输出到 Sensa 监听端口。检查有效、帧变化与 AvatarRootLocal 来源后，仍在同一根点面板两点校准。截图冻结、身份变化或超时使数据无效；它采集所选 CPU 根的原生蒙皮点，不等于 SPS 形变曲线或最终表面。

后两条生成的是实验空间映射；保存“允许实验空间输入”仍是必要步骤。先保留设备输入关闭核对预览，再按轴限制进行设备测试。QuickStart 阶梯台是内部合成测试工具，不是正式 SPS 定位入口。

## 设置

轴配置支持十二轴：L0–L2、R0–R2、V0–V2、A0–A2。每轴有输出边界、映射范围、速度上限、反向、锁定／忽略和指令形式。默认配置不能删除；删除其他配置时，其输出引用回到默认配置。先按设备标定设置，模板值不等于硬件保证。

日志位于展开区，可按类别和级别筛选。错误排查先保留实际消息、参数路径、来源和最后值。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 无 OSC 参数 | VRChat OSC、实际 OSC 模式、监听保存、端口占用、来源过滤 |
| 有参数但不动 | 输入许可、输出启用／连接、已保存映射、门控、实验阻断 |
| SPS 无匹配 | 生成器和实际路径；现代 VRCFury 与旧 Sensa 路径不同 |
| 方向相反 | 映射和轴配置是否重复反向 |
| 静止后停止 | 输入超时；旧 Point／Handle 检查最旧通道，新固定根检查生产端心跳，Shader 检查帧更新 |
| 预览变但硬件不动 | 预览不是反馈；核对传输、固件、供电和设备校准 |

## 配置与其他设备访问

配置默认是程序旁的 `config.json`；可用 `SENSA_CONFIG_PATH` 指定位置。解压更新时保留配置，发布包不包含自己的设备设置。

默认仅本机访问。需要局域网控制时，将 WebUI 监听地址设为适当接口，并在启动前设置 `SENSA_ACCESS_TOKEN`；密码为该 token，Basic 用户名任意，或使用 Bearer 认证。普通 HTTP 不加密，勿直接暴露互联网。语言选择存于当前浏览器；切换语言不改变运行状态或草稿。
