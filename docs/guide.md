# Sensa 使用指南

测试 FullFlow Avatar 和测试世界时，先按 [三端联动路线](lab-workflow.md) 操作；其中列出了每项测试的菜单、预设、实际参数和预期值。

第一次连接 OSR 请先走 [下载 → Avatar 组件 → 测试世界 → 设备](quick-start.md) 的完整流程。下文用于查询各功能。

## 1. 启动并连接输出

解压后保留整个目录。Windows 双击 `Sensa.exe`；Linux/macOS 在终端进入该目录执行 `./Sensa`。如果解包工具没有保留执行权限，可为 `Sensa` 文件添加当前用户的执行权限。macOS 的预览程序尚未签名公证；系统阻止启动时可按系统提示处理，或使用源码构建。

浏览器打开 `http://127.0.0.1:5086`。第一次使用时先保持输入开关关闭。

在“输出”添加设备：

| 输出 | 需要填写 |
| --- | --- |
| TCode 串口 | 设备串口，例如 Windows 的 COM3、Linux 的 /dev/ttyUSB0、macOS 的 /dev/cu.*；账户须有设备访问权限 |
| TCode UDP / TCP | 接收端地址与端口 |
| Intiface | 已运行的 Intiface Central WebSocket 地址；使用 Central 时关闭“管理引擎进程” |

启用并连接输出不会自动移动设备。TCode 的每个输出可以选择不同的轴配置；先限制行程、方向和速度，再测试。程序不附带 Intiface 引擎。

## 2. 选择输入

- **手动**：拖动滑条，再更新位置；“持续更新”会在输入启用后随滑条变化发送。
- **OSC**：用于 VRChat 和其他 OSC 来源，按下节设置。
- **脚本**：载入 funscript，检查播放范围、速度与循环设置后播放。

切换页签只是浏览界面，点击“应用输入方式”才改变运行模式。输入开关关闭时可以观察和编辑，不会正常发送运动。

## 3. 接收 VRChat OSC

1. 在 VRChat 开启 OSC；在 Sensa 的 OSC 页启用监听并保存。
2. 默认监听地址为 `127.0.0.1:9001`。确认发送端使用相同端口；这个 UDP 端口与 WebUI 的 HTTP 5086 端口无关。
3. 点击“应用输入方式”，在“参数与映射”确认参数出现。FT 默认隐藏，必要时打开“显示 FT”。
4. 有多个来源时先固定来源，避免把不同头像或程序的数据混用。
5. 选择合适的[预设](presets.md)。导入预设只生成草稿，检查后点击“保存并应用映射”。

普通 SPS 用户选择对应 Socket / Plug / 触碰预设。需要额外空间测量时，再按 [Unity 指南](../unity/top.sealoong.sensa/README.md)安装资产。

## 4. 校准位置输入

OSC 下有三个子页：

- **参数与映射**：连接设置、参数工作台、预设及映射编辑。
- **空间诊断**：检查点位、完整采样、偏移和异常原因。
- **量程校准**：为本地点 / PB 选择轴，采集期望的 0% 和 100% 位置。

例如：Z=10 cm 为 0%，Z=5 cm 为 100%，则 Z=7.5 cm 应预览为 50%，方向自动反转。采集 PB 时保持抓取。生成草稿后会返回映射页，再确认目标轴和范围并保存。

模板范围不是校准结果。不同目标/来源不能混用；过小范围或无效位置不能采集。普通根部和共享根部只有诊断位置，不能据此校准完整行程。

## 5. 开始与停止

确认轴限制、映射与方向后打开输入开关。输出卡片显示各自最近发送的目标：TCode 为 0–999，Intiface 为位置或震动百分比。

这些是命令目标，不保证机械设备已经到位。UDP 本身没有远端确认。输入关闭、门控关闭或精确位置失效时会请求停止；解除急停不会自动重新启用输入。

## 常见问题

| 现象 | 先检查 |
| --- | --- |
| OSC 没有数据 | VRChat OSC 开关、监听端口占用、是否应用 OSC 输入、来源过滤 |
| 有参数但不动 | 输出启用/连接、输入开关、映射是否保存、门控和定位是否有效 |
| 方向相反 | 校准端点与输出轴的反向设置；不要在两处重复反向 |
| 两个输出数值不同 | 各自的轴映射、锁定和边界设置；这可能是预期行为 |
| 坐标无效 | 缺路、0/1 饱和、范围、非均匀缩放、混入其他 Sender |
| 停止一段时间后急停 | 是否开启“断流停止”；增量 OSC 静止时可能不重发，默认应关闭 |
| 串口列表没有友好名称 | 非 Windows 平台可能只显示设备路径，可以手动选择；检查系统权限 |

## 手机与局域网访问

WebUI 支持窄屏。默认只允许本机访问；跨设备使用时按需将 WebUI 监听地址改为 `0.0.0.0`，启动前设置 `SENSA_ACCESS_TOKEN`，手机打开电脑的局域网地址与 5086 端口。认证用户名任意，密码为该 token。普通 HTTP 不加密，不应直接暴露到互联网。

配置默认写在程序旁的 `config.json`，也可用 `SENSA_CONFIG_PATH` 指定位置。更新程序时保留自己的配置。

启用断流停止后，门控信号持续更新不能替代运动数据：位置/深度停止更新时仍会停止。SPS 更换为较短目标时，先在未饱和位置重新学习长度；异常 Root/Tip 值会清除已学长度。只更新 Tip 的 OSC 增量也会重新计算深度。
