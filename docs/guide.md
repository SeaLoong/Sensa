## 准备、应用输入方式，再启用输入

选择来源、准备输出并保存。在控制中应用**手动、OSC、脚本、协议或组合**，再启用输入。添加协议来源后，即可使用协议页签。

每个输出分别管理连接与启用状态。输入运行时，已连接的输出接收当前有效目标。保存配置、切换已应用方式或载入其他脚本会关闭输入；新设置准备好后重新启用。急停会停止全部输出并保持，直到解除。

## 控制

### 手动与脚本

手动首先显示 L0／L1／L2；展开旋转、振动与辅助轴后可以使用全部十二轴。调整滑条或数值后点击**发送一次**，也可以开启**连续发送**。发送设置使用所选轴配置，或指定时长／速度。

载入 funscript 后，时间轴显示轨迹与光标。播放器提供 **0.1–4×**、循环、A–B、时间码和关键帧跳转。暂停保留光标和目标；跳到开头读取文件的首目标，停止则将时间和播放器目标归零。脚本输入启用时，暂停中的跳转／步进可以发送选中目标。

### 组合输入

需要多种来源共同参与时使用组合。例如触碰读数提供强度、手动滑条调节比例、脚本提供节奏。在流程创建并保存计算，再让输出绑定选择其结果。[完整示例](signal-pipeline.md#同一个结果连接多个输出)

### 输出

添加输出、选择类型并填写连接。在**输入到输出绑定**中选择来源、目标和范围。保存、连接并启用输出。诊断区域显示原始值、转换值与最近指令。

| 输出 | 主要设置 |
| --- | --- |
| TCode | 串口／UDP／TCP 地址与轴配置 |
| Intiface | Central 地址、设备与功能映射 |
| Handy／Lovense／Autoblow／VacuGlide | 设备 API 连接及可用控制／脚本 |
| OSC | 目标 IP／端口、路径与值类型 |
| DG-LAB | 中继、APP 配对、设备、通道和上限 |
| MIDI／HTTP／WebSocket／MQTT | 端口或地址、控制器／主题与量程 |
| 录制 | 来源、轨道名称与文件格式 |

在 TCode 轴配置中设置物理方向与行程。Intiface 从 Central 扫描设备功能；功能映射将旋转等能力连接到指定来源轴。[连接参考](protocol-inputs.md) · [绑定配置](signal-pipeline.md#添加输出与绑定)

### 接收网站的串口或蓝牙指令

网站允许填写 Intiface 地址时，可使用 Sensa 的 Buttplug 虚拟设备输入。串口或蓝牙来源使用[协议桥工具](../tools/protocol-bridge/README.zh-CN.md)接入 Sensa 的 TCode 输入，再由同一流程发送到 OSR 或其他目标。

多种 Web 协议可以通过不同路径共用监听端口，各来源保留自己的通道与会话。[共享端口与桥接示例](protocol-inputs.md)

### L0 录制

快捷 L0 录制器记录当前主轴轨迹。结束后导出单轴 funscript，并可简化曲线。面板保留末尾保持段，达到 100000 帧时提示。重新录制会先询问是否替换现有内容。

### 录制输出

录制输出可以选择指定来源、保存多个轨道，或与设备输出同时录制。Funscript 使用转换后的 0–1 数值，每个连续有效片段生成一个文件，可下载、播放或作为计算回放。JSON Lines／CSV 保存诊断样本。[录制与回放](signal-pipeline.md#录制与观察)

## OSC

### 参数与来源

应用 OSC 或组合，再查看接收值。**浏览来源**筛选列表，**使用来源**选择运行时来源。搜索、分类与置顶覆盖完整目录，每页最多显示 100 个参数。

打开参数可查看含义、类型、单位与样本时间。**冻结预览**保持显示样本，接收继续运行，输出由顶栏单独控制。可以隐藏 FT 参数，已映射和置顶项仍保留。

### 没有得到预期结果时先看哪里？

| 现象 | 检查位置 |
| --- | --- |
| 没有目标参数 | 搜索／分类／来源筛选、OSC 方式和发送目标 |
| 参数变化但映射没有读数 | 使用来源、完整路径、已保存配置与映射状态 |
| 数值看起来不变 | 继续预览、接收状态与样本时间 |
| 输出连接但没有发送 | 已应用输入方式、启用状态、来源有效性与目标范围 |

报告问题时保留完整路径与原始错误文字。[参数字典](osc-parameters.md)

### 将输入变为动作（映射）

选择[预设](presets.md)或创建映射。设置来源／路径与目标角色、采集输入起止值、选择曲线并保存。路径建议随输入筛选；路径支持完整匹配、单段 `*`、跨段 `**` 和分号／换行别名。

映射预览展示转换值。门控角色可以加入触碰区域或启用状态等条件。[校准与角色](computed-signals.md)

### 先融合输入（计算信号）

在流程添加计算与输入。例如 0.2 和 0.8 以 1、3 加权后得到 **0.65**。加入平滑，再将该结果送给振动与 Avatar 效果。

空间预设以 XYZ 组设置距离、平面深度／偏移和方向夹角。跟随平面模板连接测量目标与 Tracking Frame 标记。保存一次，即可被多条绑定复用。[操作与示例](computed-signals.md)

### 接收、发现与转发

- **接收：**监听地址、端口、来源与可选超时。
- **OSCQuery：**发现端点、订阅／轮询参数，并广播 Sensa 接收器。
- **Hub：**按事件或固定频率向多个 UDP 目标转发收到的消息。
- **OGB 心跳：**向 VRChat 的接收端发送参数发布心跳，常用端口为 9000。

正数接收超时在相关输入过期时停止；默认值 0 适合仅在数值变化时发送的应用。

### 从根点位置控制：先查看，再校准

安装[定位方案](usage-scenarios.md)，选择目标，查看坐标、单位与样本时效。把期望起点采集为 **0%**，终点采集为 **100%**，保存生成的映射并启用空间输入。

SPS 四点／Shader 使用 Avatar 根局部坐标；Contact 直接定位使用 Avatar 根米制坐标和 m/s 速度。按所选量的单位分别校准。[定位参考](positioning.md)

## 流程

流程集中管理计算、输出和整套方案。直接绑定可以省去计算；多个目标需要处理后的读数时，添加具名结果供它们复用。

**保存与载入整套方案**一起导出计算、映射、轴配置和输出，导入预览会先显示受影响数量。录制回放可将已有文件重新送入计算图。[信号流程指南](signal-pipeline.md)

## 设置与帮助

轴配置保存范围、反向、速度、锁定和动作设置。可以为另一设备复制配置，再到对应输出中选择。协议输入管理网络／串口监听与通道，日志支持按级别筛选。

同源桌面标签页共用实时连接，各自保留草稿。启动时识别已经打开的工作台；命名实例分别保留配置与端口。[多实例](quick-start.md#运行多个实例)

## 图解接近、触碰与位置

从帮助打开[参数图解](https://sealoong.github.io/Sensa/parameter-geometry.html)，或使用桌面版离线图解。选择场景、移动目标，将参数读数与几何变化对照。轴滑条用于精确调整，视图控制提供 3D／XZ／等轴展示。

SPS2 Root／Tip 和 SPS1 PenOthers／Close 解释深度读数，Touch、Frot 与 Zone 场景解释强度。完整定义见参数字典。[OSC 参考](osc-parameters.md) · [首页](../README.zh-CN.md)
