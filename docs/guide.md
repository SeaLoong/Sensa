# 工作台使用指南

**简体中文** | [English](guide.en.md)

先用[首次使用](quick-start.md)完成一条简单流程，再通过导航切换“控制、OSC、流程、设置”。桌面上导航位于左侧，较窄窗口中位于顶栏下方；当前页面的标题和说明告诉你可以在这里做什么。顶栏始终显示当前输入方式、输入开关和急停。

| 想做什么 | 打开哪里 |
| --- | --- |
| 调节手动数值或播放脚本 | **控制** → 手动／脚本／组合 |
| 查看 OSC 参数、含义和来源 | **OSC** → 参数 |
| 设置接收地址、发现或转发参数 | **OSC** → 接收与转发设置 |
| 添加计算、连接多个输出 | **流程** → 计算信号／输出 |
| 录制、下载和回放 funscript | **流程**或**控制** → 录制输出 |
| 保存或载入整套交互 | **流程** → 保存与载入整套方案 |
| 调整设备方向、行程和运动方式 | **设置** → 轴配置 |

## 准备、应用输入方式，再启用输入

先准备来源、计算和输出，保存设置；在“控制”选择手动、OSC、脚本或组合，点击“应用输入方式”，最后“启用输入”。页面中的准备状态会提示尚需完成的步骤。

保存配置、切换输入方式或更换脚本时，输入会关闭，当前输出停止。准备好后再启用。急停保持到手动解除；解除后同样需要启用输入。

输出有独立的启用和连接状态。输入运行时，新连接的已启用输出会接收当前有效目标，连接前先检查顶栏状态。

## 控制

### 手动与脚本

手动区先显示 L0／L1／L2，展开后还可调旋转、振动和辅助轴，共十二轴。调整滑条或数值，点击“发送一次”；需要让输出跟随调整时，开启“连续发送”。“发送设置”可沿用轴配置，或指定移动时长／速度；“清除覆盖”恢复轴配置。

导入 funscript 后，时间线显示当前播放位置与轨迹。支持 0.1～4 倍速、循环、A–B 区间、时码与关键帧跳转。暂停保留游标，Stop 回到开头，卸载移除脚本。脚本输入已启用时，即使暂停，也可通过定位或步进发送选定位置。

### 组合输入

“组合”让多种来源一起参与计算和输出连接。例如，OSC 触碰值决定交互强度，手动滑条调整整体比例，脚本提供基础节奏。先保存来源和计算，再应用“组合”并启用输入。[搭建示例](signal-pipeline.md#同一个结果连接多个输出)

### 输出

点击“添加输出”，选择方式，再填写这个输出内部的地址或设备。打开“输入到输出的连接”，选择来源、目标和量程；保存后启用输出并确认连接。诊断区显示最近目标、原始值、换算结果和有效状态。

| 输出 | 常用设置 |
| --- | --- |
| TCode | 串口或 UDP／TCP 地址，使用的轴配置 |
| Intiface | Central 地址、实际设备及位置／振动功能 |
| OSC 参数 | IP、端口、参数地址、Float／Int／Bool 类型 |
| DG-LAB | 中继、APP 配对、设备、通道与强度上限 |
| MIDI／网络应用 | 系统 MIDI 端口，或接收服务与字段／主题 |
| 录制 | Funscript 轨道或诊断格式、来源与范围 |

TCode 的方向、行程和速度在轴配置中设置。Intiface 连接单独运行的 Central；振动默认使用 V0，也可选择 V1／V2 或 L0。OSC 输出的“回写到 VRChat OSC”会准备常用接收目标，参数须在当前 Avatar 中配置为可写。[各输出的完整操作](signal-pipeline.md#添加输出与绑定)

### L0 录制

L0 快捷录制保存当前主轴的动作目标。停止会保留末值的保持时间，导出时可简化轨迹，得到单轴 funscript。录制最多 100000 帧；活动导出会先完成录制，输入状态保持当前设置。重新录制前会确认是否清空旧缓冲。

### 录制输出

需要选择来源、录多条轨道或同时记录交互时，添加“录制”输出。默认 Funscript 格式，输出范围设为 0～1；每条绑定的连续有效片段保存为独立文件。完成后可下载、载入脚本播放器，或回放为信号。

JSON Lines／CSV 用于分析信号，会保留原始值、换算值和无效区间。[录制与回放步骤](signal-pipeline.md#录制与观察)

## OSC

### 参数与来源

应用“OSC”或“组合”，检查接收已运行，再查看参数。“浏览来源”决定列表显示什么；“使用来源”决定实际读取什么。切换使用来源会关闭输入，检查新读数后再启用。

用搜索、分类和置顶缩小列表，每页最多 100 项，可翻页或输入页码。筛选作用于整个参数目录，数值更新保留当前页。“显示 FT 参数”控制 FT／v2 前缀参数的显示，已映射和置顶参数保留可见。

点击参数查看含义、类型、单位、来源与样本时间。“冻结预览”保留列表和详情的观察样本，此时接收和输出继续运行；需要停止输出时，关闭输入或急停。目录或连接变化时，详情会标明当前保留的样本状态。

### 没有按预期工作时，从哪里检查？

先关闭输入，每次检查一个环节，按界面现象排查：

| 界面现象 | 先检查 | 下一步 |
| --- | --- | --- |
| 找不到参数 | 清空搜索，查看全部分类／来源，需要时显示 FT 参数 | 检查当前为 OSC／组合方式、监听运行，以及发送端目标端口 |
| 参数变化，映射没有读数 | 对照“使用来源”、完整路径和未保存提示 | 修正并保存，再检查实时读数 |
| 列表停在旧值 | 查看“继续预览”按钮 | 恢复预览；需要停止动作时关闭输入或急停 |
| 已连接但没有输出 | 查看实际输入方式、输入开关、映射／连接状态 | 按显示原因检查来源、范围和条件，再启用输入 |

报告问题时，记录操作步骤、当前输入方式、来源、完整路径和错误原文；设备问题再描述实际反应。自动检查结果可在对应提交的 Actions 和[验证记录](e2e-status.md)中查看。

### 把输入转换为动作（映射）

从[预设](presets.md)开始，可选择替换或追加，再保存。每行选择来源、参数或计算结果，以及目标角色；输入量程决定读数起点和终点，曲线决定中间响应，输出区间决定目标范围。

编辑路径时，输入片段可筛选建议，也可填写完整路径。完整段 `*`、跨段 `**` 和分号／换行别名的规则见[计算指南](computed-signals.md)。单条模拟可先检查换算，再保存并查看实时结果。

“门控”表示动作生效的附加条件，例如目标足够接近。Close 可用于限定触碰区域；`GateEnable` 添加允许条件，`DepthOverride` 提供深度覆盖。角色和同轴优先关系见[计算与轴映射](computed-signals.md#有效结果与样本时效)。

### 先组合多个输入（计算信号）

在“流程”点击“新增计算信号”，命名并选择运算，再添加输入。保存后，输出连接可直接选择该计算；“用于轴映射”则创建到动作轴的引用。“OSC → 映射”也提供同一组计算的编辑入口。

展开“空间计算预设”，可以成组配置 XYZ，直接测量两点距离、相对平面的深度与偏移、方向夹角。Unity 的 Tracking Frame 配好后，“跟随移动平面”模板会按所选目标和平面建立计算草稿，检查并保存后即可连接输出。

例如，将两项强度 0.2、0.8 按 1∶3 加权，得到 0.65；给它加平滑，再同时送到振动和 Avatar 效果。实时结果使用已保存配置，草稿的未保存提示会在成功保存后消失。[运算与示例](computed-signals.md)

必需输入失效时，相关输出连接停止，其他有效连接继续。输入仍启用时，新有效样本可以恢复该连接；需要持续停止时，关闭输入或使用急停。动作轴映射按各自的门控规则运行。

### 接收、发现与转发

- **接收**：配置监听与来源。常规输入超时默认为 0，适合仅在变化时发送的参数；正值超时会在相关数据断流时触发急停。
- **OSCQuery**：发现参数、订阅更新或轮询，也可广播本机接收服务。
- **Hub**：把收到的 OSC 转发到多个 UDP 目标，可选事件或固定频率发送。
- **OGB 心跳**：需要时显式启用，目标为 VRChat 的接收地址，通常是 9000；OSC 接收运行时每 5 秒发 true，停止时尝试 false。

### 用根点位置控制动作：先观察，再校准

先按[方案指南](usage-scenarios.md)准备 SPS 四点定位、Contact 或 Shader。根点面板显示对象、来源、测量状态和读数；固定对象后选择想使用的指标。

位置可选 X／Y／Z 或 Distance。Contact 提供速度与 Speed（m/s）、ProximitySpeed（接近值／秒）；Shader 还提供 Right／Forward 轴向和 AvatarScale。选择“定位测量”（SensaPoint）即可让这些读数参与计算或输出，同时保留有效性检查。

把目标移动到动作起点，采集为 0%；再移动到终点，采集为 100%。两次采集使用同一对象、来源和指标。检查预览方向和范围，替换映射草稿并保存，最后允许实验空间输入、启用当前输入。

Contact 位置使用米；SPS 四点定位和 Shader 位置使用 Avatar 根局部单位。按所选指标分别校准，小幅检查设备方向与停止。[字段、单位和条件](positioning.md) · [Contact 设置](contact-sdk.md)

## 流程

“流程”集中管理计算、输出和整套方案。可以直接连接来源，也可以建立计算后让多个输出引用同一结果。[完整流程与示例](signal-pipeline.md)

1. 添加需要的计算，设置运算与输入，再“保存计算与映射”。
2. 添加输出，在连接中选择来源、目标和量程，再“保存输出”。
3. 在“控制”应用所需输入方式，启用输出并确认连接，最后启用输入。

“控制”和“流程”管理同一组输出。展开“保存与载入整套方案”导出已保存的计算、映射、轴配置和输出；导入前查看目标和数量，应用后选择要启用的输出。导出前先保存草稿。

录制文件可下载或载入脚本播放器，“录制回放”可将它重新作为计算来源。[录制操作](signal-pipeline.md#录制与观察)

## 设置与帮助

在轴配置中设置每轴范围、反向、速度、锁定和运动方式。可以复制配置用于不同设备，再给各 TCode 输出选择对应配置。日志可按级别筛选，排查时保留原始信息。

帮助连接[方案选择](usage-scenarios.md)、[参数说明](osc-parameters.md)和安装指南。界面与图解支持自动语言和手动选择，切换时保留草稿。在线文档会尽量保留对应章节，宽表格和代码可单独横向滚动。

同源多个标签页会在浏览器支持时共用实时连接，各页保留独立草稿。关闭一页后，其他页面可继续使用；恢复页面时重新连接状态。[共享行为与浏览器条件](signal-pipeline.md#页面与连接共用)

## 用参数图解理解接近、接触与位置

打开[在线图解](https://sealoong.github.io/Sensa/parameter-geometry.html)，或发行包里的 `docs/parameter-geometry.html`。十一个场景提供 3D、XZ 和立体 SVG；拖目标改变选定平面的坐标，拖背景旋转视角，也可用滑条精确调节。

选择 **SPS2 · PenOthersNewRoot / PenOthersNewTip** 或 **SPS1 · PenOthers / PenOthersClose** 观察深浅相关读数；Touch、Frot 和区域场景展示触碰强度。参数按字典序排列，共同前缀的短名称在前。

灰色外形帮助辨认位置，蓝色和橙色显示检测区，绿色显示当前可测区域。“模拟收到有效样本”可切换有效／失效状态。先在图解理解数值，再到工作台检查实际输入和输出。[首页](../README.zh-CN.md)
