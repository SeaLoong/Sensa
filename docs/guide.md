# 工作台使用指南

**简体中文** | [English](guide.en.md)

工作台分为三个主区：“控制”负责手动、脚本和设备；“OSC”负责接收参数并把它们转换为动作；“设置”负责轴范围、速度和日志。顶栏显示当前连接、正在使用的输入方式、输入是否启用以及急停状态，弹窗内也能急停。第一次连接请先看[首次使用](quick-start.md)。

## 准备、应用输入方式，再启用输入

先在手动／OSC／脚本页签准备参数和输出，再点击“应用输入方式”，最后点击“启用输入”开始联动。顶栏始终显示当前正在使用的方式；准备状态会列出待完成的步骤。可通过“添加输出”接入设备，或从帮助选择适合的接入方案。

保存配置、更换实际模式、导入或替换脚本时，输入会先关闭并停止。解除急停后，需要重新启用输入。设备输出分别管理连接与启用状态；输入正在运行时，新连接的已启用输出会接收当前有效目标。

## 控制

### 手动与脚本

手动先显示 L0／L1／L2，旋转、振动和辅助轴在展开区内，共十二轴。编辑数值／滑条后发送一次，或允许持续跟随修改。“发送设置”选择跟随轴配置、指定时长 I（ms）或指定速度 S；默认数值表示速度上限。“清除覆盖”恢复轴配置中的发送设置。

funscript 导入后显示时间、轨迹密度与播放控制。支持 0.1–4 倍速、循环、A–B、时码与关键帧定位；暂停保持游标，Stop 归零游标，卸载清除文件。Script 输入已启用时，暂停状态下也可用显式定位或步进发送所选目标。

### 输出

每条输出按名称／目标／操作排列，可编辑、启用、连接与断开；详细诊断按需展开。

- TCode 串口使用 115200／8N1，可枚举端口并请求设备信息；UDP／TCP 使用明确地址与端口。
- Intiface 默认连接单独运行的 Central，可扫描设备并查看支持的特征。使用自管引擎时，在对应模式中设置引擎端口。
- 振动来源默认 V0，也可选择 V1、V2 或 L0。振动强度跟随所选轴；具备位置特征的设备使用对应的位置命令。
- 轴配置决定 TCode 的移动范围、方向、限位与运动方式。输出详情用位置和时间戳记录最近发送的动作目标。

### L0 录制

录制分发前的 L0 动作目标。停止会保留末值保持时间；达到 100000 帧自动结束。活动导出先停止录制；停止录制不关闭输入。重新开始需确认清空旧缓冲，取消保留它。

导出为单轴 funscript actions，可按需要简化轨迹，便于之后重新播放或编辑。

## OSC

### 参数与来源

先应用 OSC 并检查监听，再观察参数。来源浏览与“使用来源”分开；只有后者改变实际信号来源。切换实际来源会关闭输入并清除旧来源的映射处理状态；检查新来源后，需要重新启用输入。先用搜索和分类缩小列表，再置顶常看参数。“冻结预览”只暂停参数列表的显示更新，接收、映射和设备控制仍继续运行；要停止动作，请关闭输入或使用急停。“显示 FT 参数”控制 FT／v2 前缀的可见性，已映射和置顶参数保持显示。

参数表每页最多显示 100 项，使用“上一页／下一页”继续浏览，或通过“页码”直接跳转。搜索、来源和分类先作用于当前目录中的全部参数，再分页显示；切换筛选条件会返回第一页，数值更新则保留当前页。这样无需一次展开几千行，也可以找到当前页以外的参数。

详情按同一路径和来源跟随数据更新，并显示样本接收时间；冻结预览时，详情也使用冻结样本。参数离开目录后显示打开详情时的样本，连接未就绪时显示最近收到的样本，界面会注明相应状态。“交互参数图解”打开本地离线页面。为参数建立并保存映射后，再启用输入开始联动。Avatar／来源生命周期变化会清理旧值与估长状态，并停止 OSC 输入。

### 没有按预期工作时，从哪里检查？

先关闭输入，再按界面现象缩小问题范围。每次调整来源、路径或量程中的一项，便于确认调整的效果。

| 界面现象 | 先检查 | 下一步 |
| --- | --- | --- |
| 找不到参数 | 清空“搜索参数”，将“分类”和“浏览来源”设为全部；需要时打开“显示 FT 参数” | 仍为空时，检查实际模式是否为 OSC、监听是否运行，以及发送端是否发往 Sensa 的接收端口 |
| 参数有变化，映射行却没有对应读数 | 对照“使用来源”和该行的完整路径；检查是否仍显示“未保存” | 修正一项后保存映射，再观察读数；保存会关闭输入 |
| 列表停在旧值，其他状态仍在变化 | 查看是否出现“继续预览”按钮 | 点击它恢复列表更新；要停止设备动作，应关闭输入或急停 |
| 输出已连接但没有动作 | 检查顶栏的实际输入方式、输入是否启用，以及“映射检查”中的原因 | 确认来源、映射范围和附加条件后，启用输入开始联动 |

需要报告问题时，记录操作步骤、实际模式、选中的来源和完整参数路径，并保留错误原文。自动检查结果见对应提交的 Actions 运行和[浏览器验证记录](e2e-status.md)；真实设备问题还需描述设备本身的反应。

### 把参数转换为动作（映射）

顶部工具栏集中预设、替换／追加、保存与恢复。[五个内置模板](presets.md)提供 OGB 深度／振动、Contact 位置／速率和原生 PB；自定义预设仍可保存和管理。

每行选择路径、角色、反向；高级项设置输入量程、曲线和输出区间。编辑“参数路径”时，可输入路径片段筛选建议，一次最多显示 50 项；仍可手工输入完整路径或通配符。建议只在正在编辑的字段中展开。完整段 `*`、跨段 `**` 与分号／换行别名可用。单条模拟可预览输入量程、曲线和输出区间的换算结果。草稿的“未保存”在成功保存后应消失；配置保存同时关闭输入。

“门控”是允许动作的附加条件，例如目标必须足够接近。`GateEnable` 增加这类条件，`DepthOverride` 可以覆盖普通深度。多个输入同时参与时的规则见[功能参考](features.md)。按所选参数的实际含义保留需要的条件，例如使用 Close 限定触碰区域。

### 接收、发现与转发

展开接收与转发设置，配置监听、来源、输入超时、OSCQuery 和 Hub。

- 常规 OSC 超时默认 0（关闭），适配只在变化时发送的来源；正值对相关数据断流锁存急停。
- OSCQuery 支持参数树／HOST_INFO、LISTEN 订阅与可选轮询，也可广播本机接收服务。
- Hub 向多个 UDP 目标按事件或固定频率转发，保留未消费原始 bundle 结构，计数显示转发活动。
- OGB 参数心跳默认关闭，须明确填写 VRChat 接收目标（通常 9000）。实际 OSC 接收运行时每 5 秒发 true，停用时尝试 false。

### 用根点位置控制动作：先观察，再校准

四点定位、Contact 与 Shader 根点面板显示对象、来源、相对 Avatar 的坐标与当前测量状态。Contact 直接定位使用物理米（AvatarRootMeters），四点定位和 Shader 使用按制作尺度解释的 Avatar 根单位（AvatarRootLocal）。Point／Handle／Pose 实验则分别显示相对各自参考对象的测量。空间输入默认关闭，完成观察与校准后再启用。

先固定要观察的对象，再选择左右 X、上下 Y、前后 Z，或距 Avatar 原点的距离。将目标移到期望的动作起点，采集为 0%；移到终点，采集为 100%。检查预览方向和范围，确认后替换映射草稿并保存。最后分别允许实验空间输入和启用当前输入。坐标失效时，相应动作停止。可先用小行程检查局部移动方向与设备动作是否一致。[定位条件](positioning.md)

Contact 直接定位还支持 VelocityX／Y／Z、Speed（m/s）及 ProximitySpeed（接近值／秒）。先安装受支持的 Beta SDK 并构建专用自身根点 Sender／Receiver；位置轴可校准细微局部深浅动作，Touch／Close 门控可确认触碰，速度指标可控制振动强弱。两次端点采集保持同一对象、来源和指标。[Beta 设置与字段含义](contact-sdk.md)

## 设置与帮助

轴配置支持新增、默认、复制／编辑和移除；唯一默认配置不可直接删除，引用会按规则修复。每轴可设范围、重映射、最大速度、反向、锁定／忽略与 None／Interval／Speed／Ramp。日志可按级别筛选，保留原始诊断便于排查。

帮助连接到[三条方案](usage-scenarios.md)、[参数字典](osc-parameters.md)与安装文档。UI 和图解语言遵循[自动识别与明确选择](languages.md)，切换保留草稿。

在线文档切换语言时，有可对应的标题就保留当前章节，否则打开文档顶部。超出屏幕宽度的表格和代码示例可单独左右滚动；使用键盘时，按 Tab 进入该区域，再用左右方向键滚动。

## 用参数图解理解接近、接触与位置

[在线版](https://sealoong.github.io/Sensa/parameter-geometry.html?lang=zh-CN)可独立使用，发行包也可打开 `docs/parameter-geometry.html`。十场景均有 3D、XZ 与立体 SVG；3D 拖目标只改所选平面两轴，拖背景旋转，复位视角不复位参数。滑条始终可用，WebGL 失败回退 SVG。

选择 **SPS2 · PenOthersNewRoot / PenOthersNewTip** 或 **SPS1 · PenOthers / PenOthersClose**，可以观察靠近 Socket 时深度相关值怎样变化；Touch、Frot 和区域场景展示相应触碰强度。参数按字典序排列，同前缀的短名称在前，便于对照实际 OSC 路径。

灰色外形帮助辨认相对位置，蓝色和橙色形状标出检测范围，放大的橙色操作柄便于拖动。绿色表示当前可测区域。勾选“模拟收到有效样本”观察正常读数，取消勾选则观察样本失效后的状态。图解适合在配置前理解数值，再到工作台完成映射并检查实际联动。[证据范围](ui-visual-review.md) · [首页](../README.zh-CN.md)
