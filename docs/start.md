# 使用指南

**简体中文** | [English](start.en.md)

让 VRChat／SPS、funscript 或手动控制驱动 OSR 等互动设备。先连接一个设备，再建立你需要的响应。

## 首次连接

- [跟随首次使用向导](quick-start.md) — 选择目标、连接一个设备，完成第一次动作。
- [找到设备连接方式](devices.md) — 查看 OSR／TCode、Intiface 等输出，以及桌面版和浏览器的选择。
- [试用 WebSensa](websensa.md) — 无需安装 Sensa，在浏览器中手动控制或播放 funscript。

## 按目标继续

- [使用 VRChat／SPS／OGB](usage-scenarios.md#已有-ogb--sps) — 接收接触参数，选择映射预设并校准响应。
- [播放 funscript 或使用滑条](websensa.md#手动控制与脚本) — 选择输入及设备使用的动作轴。
- [连接网站或其他播放器](protocol-inputs.md) — 让桌面版 Sensa 接收控制，再发送到设备。
- [录制交互或组合输入](signal-pipeline.md) — 保存 funscript 轨道、平滑数值，或送到多个输出。

## 设备与连接

- [OSR 与 TCode](devices.md#osr-与-tcode) — 连接串口或网络动作控制器，设置设备行程。
- [Intiface 设备](devices.md#intiface-设备) — 发现设备，选择它的位置、振动或旋转功能。
- [选择桌面版或 WebSensa](devices.md#选择桌面版或-websensa) — 查看所需连接适用的运行方式。
