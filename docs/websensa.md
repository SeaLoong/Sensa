# WebSensa

**简体中文** | [English](websensa.en.md)

[打开 WebSensa](https://sealoong.github.io/Sensa/websensa/)，在浏览器调节信号、播放 funscript，并同时控制多个输出。页面直接运行，无需先启动本机 Sensa 服务。

WebSensa、Node.js 服务与 Electron 共用一份工作台和一份 TypeScript 信号引擎。**控制、OSC、流程、设置**保持相同布局与控件。浏览器在页面运行引擎；服务端 WebUI 与 Electron 连接 Node.js 宿主。可用连接由宿主及其已安装的适配器决定。

## 连接输出

1. 在**控制 → 输出**选择**输出类型**，点击**添加输出**。
2. 在**输出设置**填写地址，选择名称、设备配置或信号连接，点击**保存输出**。
3. 在输出卡片点击**启用**。串口与蓝牙通过浏览器选择设备；配置 Web Serial 时可点击**选择串口**。
4. 准备输入，再打开顶部**输入启用**开始发送。

添加更多卡片即可同时发送信号。每张卡片分别显示连接、数值与错误。保存配置沿用可执行版本的行为：关闭输入，保留未改变的连接，等待再次启用输入。

## 手动控制与脚本

**手动**支持全部十二轴：**L0–L2、R0–R2、V0–V2、A0–A2**。勾选参与输出的轴。滑条使用 **0–999**，信号引擎转换为 **0–1**，再由输出配置决定设备量程。**发送一次**更新目标，**连续发送**跟随滑条变化。展开更多轴可调整旋转、振动与辅助控制。

播放文件时，选择**脚本**，按提示点击**应用输入方式**，再**选择脚本**。`.funscript` 或兼容 `.json` 文件会提供真实首位置。选择**脚本目标轴**、播放倍率、循环或 A–B 区间，再启用输入并播放。时间轴支持定位、逐动作步进与键盘操作。

非循环脚本播放到末尾时，保留末目标与当前输入状态。**停止**结束播放并请求停止输出；暂停保留光标位置，同时停止输出。**紧急停止**停止所有输出，解除后需要重新启用输入。

**录制 L0 目标**记录共享引擎计算出的主轴位置。开始录制，调节或播放信号，再**停止录制并导出**。需要独立轨道或信号数据时，添加**信号录制**输出，配置连接并选择 Funscript、CSV 或 JSON Lines。完成的文件可以下载、载入脚本播放器或作为回放来源。

## 浏览器连接

| 输出类型 | 目标与行为 |
| --- | --- |
| Intiface | Buttplug v3 WebSocket；读取服务端提供的位置、振动与旋转功能 |
| TCode WebSocket／串口 | 使用共享轴配置、量程与运动设置编码选中轴；串口通过 Web Serial 连接 |
| Sensa · HTTP／WebSocket | Sensa 轴命令消息，可连接另一份 Sensa 的协议输入或兼容接收端 |
| HTTP JSON／WebSocket JSON | 将独立信号连接编码为 `{address, value, type, …}` 消息 |
| MIDI CC | MIDI 输出与 `CC/通道/控制器` 信号连接 |
| Bluetooth LE | 选择设备、支持的 GATT 协议和来源轴 |
| 信号录制 | 页面内的 Funscript 轨道、CSV 或 JSON Lines |

两类 JSON 使用不同消息格式。**Sensa · HTTP／WebSocket**使用[协议输入](protocol-inputs.md#自制应用的-httpwebsocket-json)识别的通道命令；WebSocket 接收端对命令返回 `{ "ok": true }`。通用 **HTTP JSON／WebSocket JSON**发送共享信号连接消息。

蓝牙支持 **LOOB、Thrust Sync、Svakom V1、Lovense 单振动、Youou VX001**。先选择匹配协议与来源轴，再启用输出。[协议与桥接详情](protocol-inputs.md#蓝牙与虚拟串口的实际接线)

Intiface 卡片默认控制**全部设备**。需要在同一套接字上拆分设备时，为每张卡片设置不同的**目标设备**或**匹配设备名称**，默认位置功能沿用可执行版本的反向 L0，可通过功能映射改变来源与方向。同名设备可以通过不同设备编号区分。MIDI 连接可以在同一端口使用不同通道／控制器。TCode 一张卡片一起发送选中轴；不同 WebSocket 路径可以共用服务端口。

## 计算、录制与图解输入

**流程**工作区与可执行版本使用相同的计算、信号连接、映射曲线、优先级和回放来源。可以组合手动、脚本与已配对输入，或将计算结果送给多个输出。网络监听属于 Node.js 宿主；独立网页不开放 UDP／TCP 或 OSC 监听端口。

在[参数图解](https://sealoong.github.io/Sensa/parameter-geometry.html)选择**发送到 WebSensa**，在打开的工作台点击**连接参数图解**。收到的数值先显示在输入面板，不自动启用输出。打开**输入启用**后再转发；来源停止或超时会关闭输入，新数值恢复预览后可以再次启用。

## 选择运行方式

| 宿主 | 可用连接 |
| --- | --- |
| 独立 WebSensa | 浏览器 WebSocket／HTTP、支持的串口／蓝牙／MIDI API、本机文件与配对图解输入 |
| Node.js 服务 WebUI | 原生监听、UDP／TCP／OSC、文件录制、厂商接口与已安装的原生适配器 |
| Electron | 在桌面窗口内使用同一个 Node.js 服务与工作台 |

输出菜单会禁用当前不可用的类型。桌面 Chromium 浏览器通常提供更完整的设备 API；Firefox、Safari 仍可使用 WebSocket 与 HTTP 输出。HTTP 接收端需提供相应 CORS 配置，HTTPS 页面连接的地址需符合浏览器混合内容与本地网络规则。

浏览器配置与语言偏好保存在本机。重新载入会准备未激活的配置，不会自动重连输出。完成的浏览器录制保留在页面内存，关闭或重新载入前请下载；原生版本的录制保存在服务端录制目录。
