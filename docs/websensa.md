# WebSensa

**简体中文** | [English](websensa.en.md)

[打开 WebSensa](https://sealoong.github.io/Sensa/websensa/)，通过滑条或 `.funscript` 控制 OSR／TCode 设备，或通过 Intiface 连接其他互动设备。它直接在浏览器运行，无需安装 Sensa。使用实时 **VRChat／SPS／OGB** 时，请按[桌面版首次使用](quick-start.md)操作。

通过**开始设置向导**选择手动控制或 funscript 播放，再跟随设备连接、输入准备与检查步骤。可以**保存进度，稍后继续**，之后通过**继续设置**返回。[完整首次使用步骤](quick-start.md)

网站或播放器联动 OSR 时，使用 **Sensa 桌面版**的[协议输入](protocol-inputs.md)，将收到的控制转发给设备。[比较设备连接](devices.md)

## 连接输出

1. 点击向导中的**连接或配置设备**，或打开**控制 → 输出**，选择**输出类型**，点击**添加输出**。
2. 在**输出设置**中填写连接，点击**保存输出**。
3. 点击输出卡片上的**启用**，确认连接成功。

**OSR／TCode**：使用 TCode WebSocket 或串口。**选择串口**会打开浏览器授权窗口。**场景预设 → 设备轴配置**可以准备轴配置，检查并保存后，再在输出上选择使用。动作前检查方向与行程。

**Intiface**：启动 Central，填写 WebSocket 地址。在**设备与功能**中填写**匹配设备名称**，限定控制设备。连接后，也可以用**目标设备**选择已发现设备；**全部设备**会控制所有匹配设备。

## 手动控制与脚本

首次动作选择**手动**；如果显示**应用输入方式**，点击它。使用向导时，检查准备好的输入并点击**完成设置**，再打开顶栏的**输入启用**。调整 **L0** 后点击**发送一次**。**连续发送**会跟随滑条调整，振动设备默认使用 V0 来源时，展开**更多动作轴**，在**输出动作轴**中勾选 **V0**，再调整它的滑条。

播放脚本：

1. 选择**脚本**，点击**选择脚本**，载入 `.funscript` 或兼容的 `.json` 文件。
2. 如果显示**应用输入方式**，点击它。主轴动作保持**脚本目标轴**为 L0。
3. Intiface 纯振动设备先将输出的**振动来源**设为 **L0 · 深度转振动**，再打开**输入启用**，点击**播放**。

播放器支持倍率、循环、A–B、定位与关键帧步进。暂停／停止会请求停止输出；非循环脚本自然结束时保留最后目标。保存设置、应用其他输入方式或载入脚本后，输入会关闭，准备好再启用。**紧急停止**停止所有输出，解除后仍需单独启用输入。

## 浏览器连接

桌面 Chrome 或 Edge 通常支持更多串口、蓝牙与 MIDI 设备。也可以使用 WebSocket 和 HTTP 输出；连接地址需要符合浏览器的 HTTPS、本地网络与 CORS 要求。

输出菜单列出可用类型，不可用项目会说明缺少的能力。连接蓝牙时，选择与设备匹配的协议配置。[设备配置、JSON 格式与桥工具](protocol-inputs.md#蓝牙与虚拟串口的实际接线)

## 计算、录制与图解输入

一个输出成功后，可在**流程**中组合输入、平滑数值或将同一结果送到多个输出。**信号录制**输出可以保存 funscript 轨道、CSV 或 JSON Lines。[计算与录制](signal-pipeline.md)

[参数图解](https://sealoong.github.io/Sensa/parameter-geometry.html)可以向 WebSensa 发送模拟读数：选择**发送到 WebSensa**，再在工作台点击**连接参数图解**。检查预览后，准备好再启用输入。

## 选择运行方式

浏览器连接、手动控制与脚本可以使用 WebSensa。VRChat／OSC、原生 UDP／TCP 监听、应用转发与文件系统录制使用 [Desktop 或 CLI](features.md#选择版本)。各版本共用**控制、OSC、流程、设置**工作台，可用连接取决于运行环境。

浏览器设置与向导进度保存在本地。刷新后输入关闭，输出不会自动重连。**关闭或刷新前，请下载已完成的浏览器录制。**
