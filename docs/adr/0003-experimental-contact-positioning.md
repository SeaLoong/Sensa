# Dedicated root producers and explicit spatial permission / 专用根点生产端与明确空间许可

固定四锚点的 Sensa SPS 与普通 Proximity 分开：Unity／桌面共享 AvatarRootLocal 几何，专用 Self 小标记及缩放门禁收窄目标模型；原始 TPS 标签、Others 和旧共享八路不被提升为可信坐标。周期快照与 32 步活动计数允许静止距离缓存，以换取 delta-only 输入的实际可用性；活动计数不证明 Contact 同帧或无丢包。旧 Point／Handle／Pose 继续按最旧通道时效拒绝混入；固定根按变化心跳，Shader 根按完整同来源字段和变化 Frame 时效检查。所有 SensaPoint／SensaPose 映射仍需显式实验许可和输入启用，失效即停止。这样支持已约束生产端的局部根坐标，同时不把低残差、CRC 或 producer ID 当成世界真值／所有者认证。[契约与限制](../positioning.md)

Sensa SPS separates dedicated four-anchor producers from ordinary Proximity: Unity/desktop share AvatarRootLocal geometry, and a dedicated Self marker plus scale gates narrow the target model. Raw TPS tags, Others and old shared eight-range inputs are not promoted into trusted coordinates. Periodic snapshots and a 32-step liveness counter permit stationary range caching for usable delta-only input, trading away any claim of atomic Contact frames or lossless delivery. Older Point/Handle/Pose retain oldest-channel age checks; fixed roots use changing heartbeats and Shader roots use complete same-source fields plus changing Frame age. All SensaPoint/SensaPose mappings still require explicit experimental and input permission, stopping on invalidity. This enables constrained local root producers without presenting fit residual, CRC or producer ID as world truth or owner authentication. [Contract and limits](../positioning.en.md)
