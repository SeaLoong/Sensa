# Experimental Contact positioning requires explicit permission / Contact 定位须显式实验许可

四个已知非共面锚点的同点真实距离足以解相对 XYZ，但 Avatar Proximity 没有共同 Sender 身份或同帧证明；四／八路都存在零残差鬼点。保留现有解算供诊断与实验，默认关闭 SensaPoint／SensaPose 输出，显式许可也不代表可靠定位；采用所有参与通道最旧时间戳、默认 1 秒上限（正值输入超时覆盖），避免新单路替旧坐标续期。这个选择牺牲增量 OSC 静止时的持续可用性；继续默认输出或仅增加 Receiver 均不能修复不可观测性，下一步须先建立可信生产者的同批 XYZ、身份、frameId、valid／存活与标定契约，当前尚未实现。[论证与源码](../positioning.md)

True ranges to one point from four known noncoplanar anchors determine relative XYZ, but avatar Proximity proves neither common Sender identity nor a shared frame; both four- and eight-range zero-residual ghosts exist. Retain reconstruction for diagnostics and experiments, disable SensaPoint/SensaPose output by default, and require explicit permission without implying reliability; use the oldest contributing timestamp and a default one-second age limit, overridden by a positive input timeout, so one fresh channel cannot renew stale coordinates. This sacrifices stationary availability with delta-only OSC. Continuing default output or adding receivers cannot restore observability; a future trusted producer must first provide batched XYZ, identity, frameId, valid/liveness and calibration. That contract is not implemented. [Analysis and sources](../positioning.en.md)
