# 浏览器验证与截图基线

**简体中文** | [English](e2e.en.md)

浏览器 E2E、自动截图和完整进程冒烟只在 GitHub Actions。本机用 `scripts/verify.py --plan` 规划受影响静态／单元检查，再执行并复用凭据。不得伪造 CI 环境。

## 三种浏览器边界

| 套件 | 真实运行什么 | 外部依赖／不能证明什么 |
| --- | --- | --- |
| Sensa 应用 | 真实服务、HTTP／WS、浏览器 UI | 回环模拟 OSC、TCode UDP/TCP、Linux PTY、Buttplug WS、OSCQuery；不是硬件或客户端 |
| 独立参数图解 | file HTML 和本地六资产、SVG 与软件 WebGL2 | 不启动 Sensa、不联网、不接设备；不是原生 GPU 捕获 |
| 文档站 | Pages 构建产物与独立静态服务器 | 导航／语言／移动布局／公开图解；不启动产品链 |

应用集成还检查随包图解链接与资产。Pages 专用套件由第四工作流执行，不等待稳定 Unity；VPM 只显示已验证稳定索引，不伪造当前开发正式版。[开发与门槛](development.md)

## 有意义的行为断言

应用同时检查实际界面与模拟线包：模式浏览与应用、许可切换、手动／脚本、暂停／定位、录制／重录、输出配置、FT 前缀、三个模板、映射保存与冲突、轴配置、来源／门控／失效停止。内部阶梯是独立标量夹具，不是内置 QuickStart 模板。

固定 SPS／Shader 场景发送明确协议模拟，验证默认阻断、实验许可、两端校准、保存映射和失效停止；不是 Unity Contact 或真实图像采集证据。OGB 心跳检查显式启用、撤销及停止后跨五秒周期不再启用，设备输入保持关闭。

语言覆盖 URL／已存选择／完整浏览器语言顺序／English 回退、受限存储、切换持久化和保留草稿／图解状态。明确语言的截图与环境识别分开，避免系统默认改变回归基线。[语言规范](languages.md)

大量参数场景使用 4096 条模拟参数持续更新，检查每页最多 100 行、直接跳页、筛选后回到第一页，以及搜索仍覆盖全部参数。参数详情分别检查实时更新、冻结后保持样本、来源消失时保留打开时的样本，以及同名路径不混用其他来源。文档站另检查双语切换后停留在对应章节，和 320px 窄屏中表格／代码块的键盘滚动。

参数图解独立检查真实 SVG 半径／胶囊尺寸、读数、键盘、同排滑条与 320 重排；WebGL 检查真实非背景像素、对象矩阵／几何／色彩、实体参考外形、相机不改目标、XZ／XY 拖动射线平面反算／锁轴／步长／限界／取消、尺寸更新和资源释放。还检查默认／复位完整入镜、标签避让／引线，以及构造失败／context loss 的 SVG 回退。YZ 的具体覆盖和全部数值以报告为准，不把存在控件当成已执行流程。

## 固定环境与失败分析

桌面 1280×900、窄屏 390×844 使用锁定 Playwright Linux 容器、字体、语言和时区；320 另作重排检查。窄视口不是实体手机，PTY 不是 Windows 驱动。[配置](https://github.com/SeaLoong/Sensa/blob/main/playwright.config.js) · [测试](https://github.com/SeaLoong/Sensa/tree/main/tests/e2e)

失败先下载 `e2e-report`，核对 expected／actual／diff、trace、服务日志、mock-wire 与最后观测值。行为错修实现；只有有意且已审变化才换基线。不要弱化断言、自动重试或不断重发掩盖问题。

## 查看本次结果

先看对应 Actions 运行的 Job summary，再下载应用的 `e2e-report` 或文档站的 `pages-verification`。两者都保留 `summary.json` 和 `summary.md`，记录本次提交、运行次数、套件、截图模式、项目与视口，以及失败用例的断言信息。[已确认的运行记录](e2e-status.md)单独维护，通用指南不写易过时的通过总数。

| 摘要字段 | 如何理解 |
| --- | --- |
| `passed`／`failed` | 实际通过／失败的用例 |
| `expectedFailure` | 用例声明预期失败且确实失败；不算通过 |
| `flaky` | 多次尝试结果不一致；不算干净通过 |
| `skipped` | 明确跳过的用例 |
| `notRun`／`interrupted` | 尚未执行／执行中被中断的用例 |
| Runner／Command | 浏览器测试程序报告的状态／该命令在 Actions 中的最终结果；两者都要核对 |

安装或构建提前失败、没有本次有效报告时，摘要记录“未运行”和零条已观测用例，不推算未加载的用例数量。达到失败上限而未执行的用例保留为 `notRun`。只有当前提交、同一次运行、完整桌面与窄屏套件的普通比较全部通过，才能生成发布所需的比较凭据；候选图片、空运行、过滤／分片、跳过和重试通过均不能替代它。

## 候选生成与接受

正常比较禁止更新基线，缺图也失败；预发布只接受同候选 SHA 的正常全量比较。需要有意视觉更新时，在远端手动运行：

```shell
gh workflow run e2e.yml --ref <branch> -f update_snapshots=true
```

先等全部必要行为通过，再下载 `e2e-baselines`，按语言／视口逐张审阅完整画面与局部。失败任务的部分截图只能诊断；下载不等于接受。记录提交、run、图片、具体问题／修正及限制后，才把审过的图放到 `tests/e2e/__screenshots__/`，与实现提交，再运行正常比较。候选生成不发布，不自动写回 Git。

只遮蔽不稳定时间／运行地址，不掩盖目标、门控或错误。长区域按真实内容分区／滚动捕获，不能从截图外推未入镜内容。对字节相同图可继承已记录审阅，对变化图必须再看。

## 证据的读法

人工用 [V1–V6](ui-quality.md)判断层级、字体、分组、配色、对齐和双语完整性。截图相等只说明回归稳定，不是审美调查。具体历史范围见[审阅记录](ui-visual-review.md)。

`quality.spec.js` 的 axe 子集、键盘／dialog 焦点、目标尺寸、重排和几何检查是自动可检底线。保留完整 violations、incomplete、版本、URL／语言／视口及未执行项，附件位于 `artifacts/e2e/ui-quality/` 并进入报告。零违规不是完整 WCAG 认证，不能用它替代视觉判断、读屏或实际触屏验收。

所有通过／跳过／重试与图片数量以具体 Actions 报告为准。Unity 上传、真实 Contacts／OSC、HMD／桌面编码和设备停止均在本套件范围之外。
