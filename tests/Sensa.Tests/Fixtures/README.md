# Unity SDK fixture

`unity-point.json` was captured on 2026-10-13 (Asia/Shanghai) from the local Sensa Worlds laboratory running Unity 2022.3.22f1 / SDK 3.10.5 in ClientSim. It contains actual `VRCContactReceiver.CalculateProximity` results for four tetrahedral anchors (cube indices 0, 3, 5, 6 at ±0.06 m), receiver radius 0.35 m, sender radius 0.001 m, and the observed target Transform position. These are historical measurements from the previous geometry. The test-only replay checks them with their original radius and spacing; they do not validate the current 2 m receiver geometry. A new Unity SDK capture is required for that claim. They are not a capture of avatar OSC or a real player's grab interaction.

`unity-point-cases.json` records eleven world SDK cases from `LabPointCases.Run`: front/back, lateral, out-of-contact, saturation, wrong radius, uniform scale, rotated frame, injected missing lane, fit-volume rejection and origin. Case 09 explicitly substitutes -1 for the missing lane; that value is fault injection, not an SDK measurement. Valid cases are compared with the captured local Transform coordinates.

Current 2 m receiver / ±0.35 m anchor geometry is covered by synthetic desktop reconstruction tests and Unity authoring contracts. The laboratory generation code uses the shared protocol constants for future captures. Unity execution is a separate check; do not relabel these stored measurements as a new capture.
