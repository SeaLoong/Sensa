# Unity SDK fixture

`unity-point.json` was captured on 2026-10-13 (Asia/Shanghai) from the local Sensa Worlds laboratory running Unity 2022.3.22f1 / SDK 3.10.5 in ClientSim. It contains actual `VRCContactReceiver.CalculateProximity` results for eight ±0.06 m anchors, receiver radius 0.35 m, sender radius 0.001 m, and the observed target Transform position. It validates desktop decoding against SDK measurements; it is not a capture of avatar OSC or a real player's grab interaction.
